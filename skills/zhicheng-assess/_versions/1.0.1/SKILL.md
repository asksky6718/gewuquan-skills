# 职业技能等级认定·自评（zhicheng-assess）

> 一句话：填 10 项基本情况 → 按现行口径逐级比对 → 出「能报哪一级 · 差哪几项 · 怎么补 · 下一步」。
> 业务对象＝**人工智能训练师职业技能等级认定**（五级／初级工 → 一级／高级技师）；「职称」只在部分申报路径里作条件表述，不是本能力名。
> 规则数据在 `references/rules.json`，本技能只照数据测算，不在页面里写死结论。

## 这个技能解决什么

职业技能等级（五级 / 初级工 → 一级 / 高级技师）的申报路径多、条件杂：工作年限、学历与专业、既有等级证书、既有职称、培养路径，不同等级各有一套路径判定，逐条手算既慢又容易看漏。本技能做三件事：

1. **逐级机械比对**：把填报信息转成可机械比对的条件，对每一级的每一条路径逐个判「满足 / 未满足」。
2. **只算不判**：给出**可申报的最高等级**、**下一级差哪几项**、**每项的补法**与**下一步要准备什么**。
3. **如实标边界**：条目里没有的情形一律标注「本条库里没有」，并附技能提升补贴提示与人工把关点。

## 典型触发句

- 「帮我做一下职业技能等级认定自评，看我能报几级。」
- 「我是本科、相关专业，工作 6 年，能报哪一级？」
- 「我没有任何证书和职称，够不够条件申报？」
- 「现在满足了哪一级？还差哪几项？」
- 「这几项差的条件分别怎么补？」
- 「下一步我该准备哪些材料？」
- 「我走学历路径还是走证书路径更合适？」
- 「我有四级证书满 4 年，能报三级吗？」
- 「技能提升补贴我这个等级能领多少？」
- 「帮我按现行口径测一遍，再列个补件清单。」

## 输入

| 字段 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `age` | number | 是 | 16–80 | 年龄（周岁）；未满 16 周岁任何等级都不能报 |
| `education` | select | 是 | 见 `rules.json` | 最高学历：初中及以下 / 中职 / 大专 / 本科 / 硕士 / 博士 |
| `major` | select | 是 | `related` / `other` | 是否属本专业或相关专业 |
| `education_extra` | select | 是 | 见 `rules.json` | 培养路径：普通毕业 / 高级工班及以上 / 经评估论证 / 两者都符合 |
| `work_years` | number | 是 | 0–60 | 累计从事本职业或相关职业工作年限（年） |
| `cert` | select | 是 | 无 / 五级…一级 | 已有职业技能等级证书 |
| `cert_years` | number | 否 | 0–60 | 该证书取得后年限；无证书填 0 |
| `title` | select | 是 | 无 / 初级 / 中级 / 高级 | 已有职称 |
| `title_years` | number | 否 | 0–60 | 职称取得后年限；无职称填 0 |
| `achievements` | number | 是 | 0–99 | 可举证业绩条数（项目 / 课程 / 获奖 / 论文等） |

- 必填缺项返回 `invalid_input`，并逐项列出 `{name, label, reason}`，不会静默给结论。
- 只读技能：不读取、不上传任何外部文件，不联网。

## 输出

统一返回 `ok` / `headline` / `boundary` / `input` / `blocks` / `evidence` / `declarations` / `uncovered` / `markdown`：

- **`headline`**：一句话结论，含可申报等级；未满 16 周岁或五级条件都不满足时如实说明。
- **`blocks`**：
  - 逐级路径清单（`list`）：每级每条路径标 `met` / `missing`，并带原 `label`；
  - **差哪几项**（`list`）：下一级未满足的路径逐条列出，附补法 `remedy`；
  - **怎么补**（`list`）：去重后的补法清单；业绩不足 3 条时附业绩补充提示（含当前条数）；
  - **下一步**（`steps`）：材料找齐、机构核验、生成材料清单三步；
  - **补贴提示**：三级 / 四级 / 五级给补贴范围提示（能否申领以参保地经办机构核定为准），二级 / 一级明确不在补贴范围。
- **`evidence`**：用到的知识库条目 `id → 原始标题`，每条结论都可回查。
- **`uncovered`**：库外情形逐条标注「本条库里没有」，不编造。
- 契约调用（无入参）返回 `status: contract` 与 `outputs` / `fields` / `sample` / `summary`。

## 人工把关点

1. **须本人核对**：学历与学籍、工作年限、既有证书与职称、业绩材料均须与原始证件逐项核对后再作申报参考。
2. **须本人核验机构**：报名前上职业技能等级评价机构公示查询系统（pjjg.osta.org.cn）查机构是否在公示名单内及其可评价的职业与等级范围。
3. **须本人确认专业**：专业是否属「本专业或相关专业」、所读专业是否经评估论证，须由本人向评价机构确认。
4. **须本人确认属地口径**：补贴与受理条件以参保地经办机构与属地人社部门核定为准，不套用其他地区口径。
5. 逐条清单见 `references/人工把关点.md`。

## 边界

- **须本人核对**：本技能只按填报信息机械比对，填报内容与原始证件是否一致由本人负责。
- **不代提交／不代签字／不代盖章**：报名、材料报送、信息填报一律由本人办理；申报表、承诺书由本人签字；单位证明、考核意见由有权单位盖章。
- **不定论、不承诺**：不给受理通过、评审通过的承诺；结论一律附「本结论按现行口径测算，以评价机构与属地人社部门核定为准」。
- **库外情形如实标注**：特级技师 / 首席技师条件、破格申报、跨省互认、机构当期报名与收费、业绩条数量化门槛，以及上海以外属地的评价机构名单与批次申报时间，均标注「本条库里没有」。
- **不适用他人**：一次只测算本人；不替代评价机构或人社部门的正式解释。
- 只读、不联网、不写任何文件；不采集账号、密码、短信验证码，不保存证件信息。
