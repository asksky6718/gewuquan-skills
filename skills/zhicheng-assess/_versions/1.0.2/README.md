# 职业技能等级认定·自评（zhicheng-assess）

> 一个「填几项基本情况 → 按现行口径算一遍」的只读技能包。
> 业务对象＝**人工智能训练师职业技能等级认定**（五级 / 初级工 → 一级 / 高级技师）；「职称」只在部分申报路径里作条件表述，不是本能力名。
> 出**能报哪一级 · 差哪几项 · 怎么补 · 下一步**，并提示技能提升补贴。
> 版本：**1.0.1** · 许可：MIT · 引擎：`assess` · 规则：`references/rules.json`

---

## 一、用途

职业技能等级（五级 / 初级工 → 一级 / 高级技师）申报路径多、条件杂：工作年限、学历与专业、既有等级证书、既有职称、培养路径，不同等级各有一套路径判定，逐条手算既慢又容易看漏。

本技能把《人工智能训练师能报几级？各级申报条件是什么？》条目的**通用申报条件**转成可机械比对的规则，做三件事：

1. **逐级机械比对**：对五级 → 一级的 17 条申报路径逐个判「满足 / 未满足」。
2. **只算不判**：给出可申报的最高等级、下一级差哪几项、每项的补法与下一步。
3. **如实标边界**：条目里没有的情形一律标注「本条库里没有」，不编造。

**它不做什么**：不定论、不承诺通过、不代提交、不代签字、不代盖章；不套用其他地区口径。

## 二、输入

一张 10 项的表单（`references/rules.json` 里的 `fields`）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `age` | 是 | 年龄（周岁），16–80 |
| `education` | 是 | 初中及以下 / 中职 / 大专 / 本科 / 硕士 / 博士 |
| `major` | 是 | 是否属本专业或相关专业 |
| `education_extra` | 是 | 培养路径（普通毕业 / 高级工班及以上 / 经评估论证 / 两者都符合） |
| `work_years` | 是 | 累计从事本职业或相关职业工作年限 |
| `cert` | 是 | 已有职业技能等级证书（无 / 五级…一级） |
| `cert_years` | 否 | 该证书取得后年限，无证书填 0 |
| `title` | 是 | 已有职称（无 / 初级 / 中级 / 高级） |
| `title_years` | 否 | 职称取得后年限，无职称填 0 |
| `achievements` | 是 | 可举证业绩条数 |

必填缺项会返回 `invalid_input`，逐项列出缺什么、为什么，不会静默给结论。

一个可跑通的样例（`rules.json` 的 `sample`）：

```json
{ "age": 28, "education": "bachelor", "major": "related", "education_extra": "none",
  "work_years": 6, "cert": "none", "cert_years": 0, "title": "none", "title_years": 0,
  "achievements": 2 }
```

→ 满足**四级 / 中级工**；下一级（三级）6 条路径全未满足，逐条给补法；业绩 2 条触发补充提示。

## 三、输出

| 块 | 内容 |
|---|---|
| `headline` | 一句话结论，含可申报等级；未满 16 周岁或五级条件不满足时如实说明 |
| 逐级路径清单 | 每级每条路径标「满足 / 未满足」 |
| 差哪几项 | 下一级未满足的路径逐条列出，附补法 |
| 怎么补 | 去重后的补法清单；业绩不足 3 条附补充提示 |
| 下一步 | 材料找齐 → 核验机构 → 生成材料清单三步 |
| 补贴提示 | 三 / 四 / 五级给补贴范围提示；二 / 一级明确不在补贴范围 |
| `evidence` | 用到的知识库条目 `id → 原始标题` |
| `uncovered` | 库外情形逐条标注「本条库里没有」 |

每条结论都带边界声明：**本结论按现行口径测算，以评价机构与属地人社部门核定为准。**

## 四、怎么装到智能体

把整个 `zhicheng-assess/` 目录拷进对应载体的技能目录即可：

```bash
cp -r zhicheng-assess ~/.workbuddy/skills/     # WorkBuddy
cp -r zhicheng-assess ~/.客户端/skills/         # 客户端 系
```

也可以把本目录作为技能源，交由承载方的通用 `assess` 引擎按 `references/engine.json` 装配：
引擎读 `engine.json` 得知用 `assess`、规则在同目录 `rules.json`，页面只渲染引擎输出，不承载业务规则。
装好后，对话里说「职业技能等级认定自评」「我能报几级」「差哪几项」「下一步准备什么材料」即可唤起。
