# 口径来源

> 本技能只引用知识库中**已核验存在**的条目；条目名一律用**原始标题**，逐字照录。
> 不在下列条目里的情形，一律在输出里标注「本条库里没有」，不编造出处。

## 一、引用的条目（id → 原始标题）

## 二、逐条对应关系

- **能报哪一级 / 差哪几项 / 怎么补** → `zhicheng_levels`：五级到一级的路径判定与补法均逐条来自该条目。
- **评价机构核验** → `zhicheng_verify`：机构公示名单查询系统与核对范围。
- **申报通道选择** → `zhicheng_channel`：三类通道与选择逻辑。
- **证书与资格区别 / 证书查询** → `zhicheng_certdiff`、`zhicheng_certquery`：证书性质与查询渠道。
- **技能提升补贴** → `zhicheng_subsidy`：三 / 四 / 五级补贴范围提示；二 / 一级不在补贴范围。

## 三、写明「本条库里没有」的（不编造）

- 特级技师 / 首席技师的逐条申报条件（新八级工序列）。
- 破格申报、直接认定、跨省（跨机构）互认的具体办法。
- 各评价机构的当期报名时间、开考计划与收费标准（须查机构公示或拨打 12333）。
- 对「业绩条数」的量化门槛；业绩条数仅在评价评审环节作参考。

## 四、边界

- 结论一律附「本结论按现行口径测算，以评价机构与属地人社部门核定为准」。
- 只引用上述公开条目口径，不引用任何内部文件或未公开资料。
- 不套用其他地区数字；属地口径以评价机构与参保地经办机构核定为准。
