# opc-aftersales · 售后与续费

## 适用场景

课程结课前后，需要把「交付结束」变成「续费／转介绍／口碑沉淀」时使用。

## 输入

- `cohort`：刚结课或临近结课的学员名单与学习结果。
- `feedback`：满意度、投诉、退费诉求记录。
- `next_offer`：下一阶段可续的产品与政策。
- `policy`：退费与补偿的授权范围。

## 步骤

1. **结课回访**：结课后 7 天内一对一回访，固定问「最有用的收获／最不满意的一点／下一步目标」。
2. **投诉分级**：按「教学效果／服务体验／费用争议」分类，级内按影响面分级；
   在授权范围内 48 小时内给方案，超出授权升级决策（W-02）。
3. **价值复盘**：把学习结果量化（前后对比），形成一份给学员的「学习成果小结」。
4. **续费动作**：按下一步目标推荐 1 个续费方案，给出老学员专属条件，约定决策时间。
5. **转介绍**：对满意度高的学员，提出 1 个低门槛转介绍动作（如邀请 1 位同学体验），
   记录来源以便市场侧复用（回流 `opc-market`）。

## 输出

- 一份回访记录与投诉台账（含处理状态）。
- 一份学员成果小结模板。
- 续费与转介绍动作清单（人、条件、时间）。

## 边界

- 退费与补偿属「钱」类决策，超出授权范围不得自行承诺（W-02）。
- 投诉与个人信息妥善保管，不得外传或用于无关用途。
