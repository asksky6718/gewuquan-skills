# 人工把关点（opc-aftersales）

售后环节两道人门：钱（结算）与级（L6/L7 晋级）——机器只挂起，永不自动。

## 一、完全不用人操心的（机器全包）

| 事项 | 机器做到哪一步 |
|---|---|
| 计量核对 | `usage_events` 按 `agent_id` 聚合并与交付对账 |
| 审计回放 | 按 trace 回放调用链，标异常中断 |
| 对账平衡校验（AS-2） | 交付记录 ↔ 计量记录 |
| 晋级链校验（AS-4） | 晋级不断层 |
| 机判级推进（L1–L5、L8） | 校验通过即写 `opc_level_after` |
| 人判级挂起（L6/L7） | 只核证据齐备性，`promotion_pending=true` |
| 三件套输出 | `renewal.json` ＋ `renewal.md` ＋ `renewal-report.html` |

## 二、必须本人上手的（四项，一个都不能少）

| # | 动作 | 为什么躲不掉 | 机器提前准备好什么 | 人做完回什么 |
|---|---|---|---|---|
| 1 | 结算放行 | 涉钱，判定权在人 | 对账单 ＋ `approval` 留痕表单 | 审批留痕 |
| 2 | L6／L7 晋级放行 | 涉钱涉对外 | 证据齐备性报告 | 放行或驳回留痕 |
| 3 | 计量异常裁决 | 对账不平的原因只有人知道 | 差异明细（逐条列） | 裁决结论 |
| 4 | 续费口径确认 | 续费信号涉及对外触达 | 续费信号清单 ＋ 触达话术草案 | 确认留痕 |

**L6／L7 永不自动晋级；结算永不自动放行——机器挂起，人拍板。**
