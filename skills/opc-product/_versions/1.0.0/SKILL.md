# opc-product · 产品与定价

## 适用场景

要新开一门课／一项服务，或现有产品卖不动、毛利不清时使用，产出可上架的产品定义与价格带。

## 输入

- `goal`：这批学员要达成的结果（可验证）。
- `constraints`：师资与交付人力、周期、可用预算。
- `market`：同类产品价格带（竞品 3 个采样）。
- `costs`：直接成本项（课时费、场地/工具、获客成本）。

## 步骤

1. **结果定义**：把 `goal` 写成「学员在 X 周后能做到 Y，以 Z 方式验收」。
2. **交付结构**：拆成「核心交付 ＋ 练习/作业 ＋ 反馈/答疑 ＋ 结课产出」四块，标注每块的工时。
3. **成本核算**：逐项列出直接成本与按课时摊销的固定成本，算出单位交付成本与盈亏平衡学员数。
4. **定价**：按「成本底线 → 市场锚点 → 价值锚点」给出低/中/高三档，说明各档差异与推荐档。
5. **上架检查**：确认交付承诺、有效期、退费规则、服务边界四条写清，避免售后争议。

## 输出

- 一页产品定义（结果、交付结构、周期、验收方式）。
- 一张成本与盈亏平衡表。
- 三档价格带与推荐档及理由。

## 边界

- 定价与让价属「钱」类决策，最终须七哥逐次放行（W-02）；本技能只给区间与依据。
- 不虚构师资与办学资质；宣传口径不得超出实际交付。
