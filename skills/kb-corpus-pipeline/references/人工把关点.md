# 人工把关点（机器不代办）

> 本技能只产出**候选**，不代替判断与放行。下列步骤必须由人或上游流程决定。

1. **候选复核**：候选条目的事实准确性、口径与时效，由业务/内容负责人复核；机械纠偏只给「有依据/存疑/无依据」三态与依据指针，**不构成事实认定**。
2. **存疑条目取舍**：标「存疑」的条目默认入候选但带标记；是否采用由复核者决定。
3. **可见性定级**：`visibility` 取 `public` / `internal` / `subject-private`，由复核者按内容定；默认 `internal`。
4. **入库放行**：候选包入库须走既有审查与入库流程，本技能不代跑。
5. **对外发布/上架**：技能上架市集、候选内容对外，均属人类门禁（钱/对外/方向/不可逆破坏），机器不放行。
6. **主体隔离**：涉及他主体名或他主体口径的内容，对外前必须清洗或挂起，按主体隔离规则处理。

## 机器已保证（无需人工重复）

- 只读外部：全程仅 HTTP GET，无发布/留言/注册；
- 内部词表零命中；
- 无依据不进候选；
- 无 YAML 元信息头；
- 一问一条；
- manifest 字段齐全、`counts.total` = 条数、可被入库层直接吃下。
