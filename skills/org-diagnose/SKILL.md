# org-diagnose · 机构经营诊断

> `min_scope: read`：本技能只读，不写盘、不联网、不代提交、不代签字、不代盖章。
> 可执行引擎为 `diagnose`（见 `references/engine.json`），业务规则的唯一事实源是 `references/rules.json`。

## 这个技能解决什么

- 把「机构类型 ＋ 主营项目 ＋ 机构规模 ＋ 当前卡点」四句话，转成一份可直接排期的经营诊断草稿。
- 按**受理段 · 市场与获客 → 产品段 · 课程与教研 → 成交段 · 报价与合同 → 交付段 · 教务与课堂 → 结算复购段 · 对账与续费**五段流水线，做关键词命中的逐段诊断；命中的段落排序靠前，未命中的给基线自查口径。
- 输出**销售获客 / 产品设计 / 教务交付**三类建议方案，每条含动作、责任角色、产出物、时限，以及知识库依据。
- 输出 **30 天可执行清单**（第 1–4 周），把方案落成可勾选的周计划。
- 规模差异写进说明：按 `references/rules.json` 的 `scale_notes` 取当前规模的落地提示。

## 典型触发句

- 「帮我们机构做个经营诊断」「我们机构现在卡在哪？」
- 「招生线索转化低怎么办」「自媒体招生内容怎么排期？」
- 「课程产品怎么设计、知识点怎么拆」「题库怎么和课程绑定？」
- 「教务交付怎么管、课堂怎么验收？」
- 「报价和合同环节要注意什么」「交付和结算怎么对账？」
- 「给我一份 30 天经营清单」「按五段流水线看看我们缺什么？」

## 输入

| 字段 | 标签 | 类型 | 必填 | 约束 | 样例 |
|---|---|---|---|---|---|
| `org_type` | 机构类型 | select | 是 | 院校 / 培训机构 / 培训公司 / 企业内训 / 知识付费 | 培训机构 |
| `main_project` | 主营项目 | text | 是 | 2–60 字 | 人工智能训练师培训 |
| `scale` | 机构规模 | select | 是 | 1–5 人 / 6–20 人 / 21–50 人 / 50 人以上 | 6–20 人 |
| `bottleneck` | 当前卡点 | textarea | 是 | 4–200 字 | 招生线索转化低 |

- 入参以 `references/rules.json` 的 `fields` 为唯一事实源；缺必填或越界，引擎返回 `invalid_input` 并逐项说明原因。
- `sample` 提供一组可直接试跑的样例输入。

## 输出

执行（带 `args`）时输出结构化结果：

- `headline`：一句话结论（优先动哪一段）。
- `blocks`：`诊断结论` / `五段诊断` / `三类方案` / `30 天可执行清单` / `说明`。
- `evidence`：本次实际用到的知识库条目（`id` ＋原始标题）。
- `declarations`：须本人核对、不代提交、不代签字、不代盖章四条声明。
- `uncovered`：库里没有、须以机构实际与主管部门要求为准的部分。
- `markdown`：可复制、可带走的《机构经营诊断报告（草稿）》。

契约（不带 `args`）时输出字段清单、样例与出什么，供能力台展示。

## 人工把关点

- **涉钱一律留人**：报价、折扣、返佣、结算金额的判定权在人；本技能只做校验与草稿，不自动定价、不放行金额。
- **对外承诺留人**：交付期、效果口径等对外话术，须由人核过再对外。
- **本人核对输入**：机构类型、规模、主营项目与卡点描述须与机构实际一致。
- **属地政策与真实数据**：具体经营数据、财务与属地合规口径不在本技能库内，须以机构实际与主管部门要求为准。
- 四条声明：须本人核对 / 不代提交 / 不代签字 / 不代盖章；详见 `references/人工把关点.md`。

## 边界

- **只给建议动作，不承诺经营结果**；本技能不替机构决策，也不对经营结果负责。
- **按现行口径测算，以机构实际与属地政策核定为准**；政策与口径变化时，以主管部门与属地最新要求为准。
- 不自动定价、不给折扣、不放行金额；涉钱环节只校验留痕。
- 不代提交、不代签字、不代盖章；不生成对外承诺，不替机构对外发布。
- 只读：不写盘、不联网；输出不含内网路径与内部代号，`evidence` 只给知识库条目标题。
