# org-diagnose · 机构经营诊断

> 技能包（数据）＋ 通用引擎（代码）：本目录只放业务规则与人读说明，执行由格物圈技能引擎 `diagnose` 完成。
> `min_scope: read`（只读）；业务规则的唯一事实源是 `references/rules.json`。

## 一、它做什么

输入机构类型、主营项目、机构规模与当前卡点四件事，输出：

1. **五段经营诊断**：受理段 · 市场与获客 / 产品段 · 课程与教研 / 成交段 · 报价与合同 / 交付段 · 教务与课堂 / 结算复购段 · 对账与续费。命中卡点词的段落排序靠前；未命中的给基线自查口径。
2. **三类建议方案**：销售获客方案、产品设计方案、教务交付方案；每条含动作、责任角色、产出物、时限与知识库依据。
3. **30 天可执行清单**：第 1–4 周逐周勾选项。
4. **说明与出处**：规模提示、机构类型差异、库内未覆盖范围，以及本次实际用到的知识库条目。

只给建议动作，不承诺经营结果；结论按现行口径测算，以机构实际与属地政策核定为准。

```
org-diagnose/

├── LICENSE                      # MIT

    ├── rules.json               # 业务规则数据（唯一事实源）

    └── 人工把关点.md             # 人读：必须人做的步骤
```

## 三、怎么用

- **试跑**：按 `references/rules.json` 的 `sample` 传四字段 `org_type` / `main_project` / `scale` / `bottleneck`，引擎返回结构化结果与可带走的 Markdown 草稿。
- **改口径**：只改 `references/rules.json`（升级版本并留 `CHANGELOG.md`），页面与引擎不承载业务规则；改数据即改输出。
- **看字段清单**：不带 `args` 执行时，引擎返回 `outputs` / `fields` / `sample` / `summary`，供能力台展示。

## 四、入参契约

| 字段 | 标签 | 类型 | 必填 | 约束 |
|---|---|---|---|---|
| `org_type` | 机构类型 | select | 是 | 院校 / 培训机构 / 培训公司 / 企业内训 / 知识付费 |
| `main_project` | 主营项目 | text | 是 | 2–60 字 |
| `scale` | 机构规模 | select | 是 | 1–5 人 / 6–20 人 / 21–50 人 / 50 人以上 |
| `bottleneck` | 当前卡点 | textarea | 是 | 4–200 字 |

## 五、边界与红线

- 不自动定价、不给折扣、不放行金额；报价、折扣、返佣与结算一律留人。
- 不代提交、不代签字、不代盖章；不生成对外承诺。
- 具体经营数据、财务与属地合规口径不在库内，须以机构实际与主管部门要求为准。
- 只读：不写盘、不联网；输出不含内网路径与内部代号。

## 六、人机分工

- **机器全包**：关键词命中的五段诊断、三类方案与 30 天清单的组装、知识库依据的逐条挂接、Markdown 草稿导出。
- **必须人做**：涉钱判定、对外承诺、输入与机构实际核对、属地政策与真实数据核定。详见 `references/人工把关点.md`。
