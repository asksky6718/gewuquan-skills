# 宣传合规自查（compliance-copy）

> 一句话：**贴一段宣传文案 → 逐句标出违禁词与风险等级 ＋ 改写建议；只标风险，不给「能发」结论。**

## 这个技能解决什么

招生、课程、证书类宣传文案里，「结果承诺、免考免学、内部名额、假冒主管部门授权、以年审等名义变相收费」这几类表述，容易被认定为虚假或误导。逐字人工排查既慢又容易漏，本技能做三件事：

1. **逐句拆**：按 `。！？；` 与换行把文案拆成句子，只对命中的句子报警，不整篇笼统吓人。
2. **逐句标**：比对风险词表与风险模式，给出命中项、风险等级（`high` / `mid` / `low`）与改写方向。
3. **只提示不背书**：机器只标风险，**不给「能发」结论**；是否发布由发布主体结合当期法规与平台规则自行判断。

## 典型触发句

- 「帮我看看这段招生文案有没有违禁词。」
- 「这句话能不能写：……」
- 「这段公众号推文有没有广告法风险？」
- 「给我把这段直播话术逐句过一遍。」
- 「海报文案体检一下，标出风险等级。」
- 「『不过退款』『内部名额』这种写法有问题吗？」
- 「这段宣传文案哪些地方需要改？」
- 「按风险高低把这段文案的问题列出来。」

## 输入

| 字段 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `text` | textarea | 是 | 2–4000 字 | 待自查的宣传文案，一次一段 |

- 多段文案请分段提交，避免一句里混入多个主题导致建议难以对应。
- 只读技能：不读取、不上传任何外部文件，不联网。

## 输出

- `headline`：命中句数与整体风险概况；**未命中也不等于可以发布**。
- `blocks[type=issues]` 逐句列出：`sentence`（原句）、`level`（`high` / `mid` / `low`）、`words`（命中的词或模式 id）、`suggestion`（改写建议）。
- `markdown`：可带走的逐句清单，便于贴回文案稿。
- `declarations` 与 `boundary`：随每次结果一并返回的边界声明。

### 风险词表（检测目标，逐句匹配）

`包过`、`保过`、`包过班`、`包拿证`、`百分百通过`、`免考`、`免学免考`、`直出`、`内部名额`、`保就业`、`保录取`、`人社部授权`、`年审激活费`、`不过退款`、`国家承认`。

> 以上为**检测目标数据**：出现即命中并给出改写建议，技能本身不对其作任何推荐或背书。

### 风险模式（正则）

- `保证.{0,6}(通过|拿证)` → 保证通过 / 取证承诺
- `(100|百分之百)\s*%?\s*(通过|拿证)` → 绝对通过率
- `(免|不用)(考试|学习)` → 免考、免学
- `(内部|内定|预留).{0,4}(名额|指标|渠道)` → 内部渠道暗示
- `(人社部|人社厅|人社局|主管部门).{0,6}(授权|指定|合作|背书)` → 假冒或夸大授权
- `(不过|不通过|考不过).{0,4}(退款|退费|全额退)` → 退款承诺
- `(保证|承诺|确保).{0,4}(就业|入职|上岗)` → 就业承诺
- `(最|第一|唯一|首个|顶级|国家级|世界级)` → 绝对化用语

## 人工把关点

1. **定稿在人**：机器只给改写提示，**不定稿、不代发、不代提交**；最终文案由发布主体确认。
2. **重大表述须复核**：涉及收费、退费、资质、授权、就业、录取的表述，须经**人工与法务／合规负责人**复核。
3. **平台规则会变**：发布前回平台当期规则与公告原文核对，不沿用旧口径。
4. **疑似虚假宣传要停手**：发现可能构成虚假或误导的表述，先暂停发布并走内部审批，不自行「改一改就发」。
5. 详见 `references/人工把关点.md`。

- 《中华人民共和国广告法》《中华人民共和国反不正当竞争法》以及主流平台公开规则的通行口径。
- 只引用**公开法规与平台规则**，不引用任何内部文件或内网资料。
- 出处与逐条对应关系见 `references/口径来源.md`。

## 边界

- **只标风险，不给「能发」结论**；未命中不等于可以发布。
- 最终口径**以市场监督管理部门与平台规则为准**。
- 本技能**不替代法律意见**；涉及行政处罚、诉讼、重大对外发布时，须咨询执业律师。
- 词表与模式为通用检测数据，不覆盖全部行业、地方性规定与平台细则。
- 只读、不联网、不写文件，不改写、不代发、不代提交。
