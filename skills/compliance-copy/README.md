# 宣传合规自查（compliance-copy）

> 贴一段宣传文案 → **逐句**标出违禁词与风险等级 ＋ 改写建议；**只标风险，绝不给「能发」结论**。
> 版本：**1.0.0** · 许可：MIT · 权限档：`read`

---

## 一、它解决什么问题

招生、课程、证书类宣传文案中，以下几类写法很常见，也很容易被认定为虚假或误导：

- **结果承诺**：包过、保过、百分百通过；
- **免除环节**：免考、免学免考、直出；
- **稀缺话术**：内部名额、内定指标；
- **假冒授权**：宣称主管部门授权、指定或合作；
- **变相收费**：以年审、激活等名义另行收费；
- **效果承诺**：保就业、保录取、不过退款。

人工逐字排查慢且易漏。本技能把文案**拆成句子**，只对命中的句子报警，逐句给风险等级与改写方向，让修改有的放矢。

## 二、它长什么样

```
输入：一段宣传文案（textarea，2–4000 字）
   │
   ├─ 按 。！？；换行 拆句
   ├─ 逐句比对 words（风险词表）与 patterns（风险模式）
   └─ 命中句输出：原句 / 风险等级 high·mid·low / 命中项 / 改写建议
```

示例输入：

> 本机构包过，免考直出，内部名额有限，人社部授权，不过全额退款。

示例输出（逐句）：

| 原句 | 风险等级 | 命中项 | 改写方向 |
|---|---|---|---|
| 本机构包过 | high | 包过 | 删去结果承诺，如实描述学习与服务内容 |
| 免考直出 | high | 免考、直出 | 如实列出须参加的考核与正规办理路径 |
| 内部名额有限 | high | 内部名额 | 改为公开可查的报名渠道与名额规则 |
| 人社部授权 | high | 人社部授权 | 资质以官方公示名单为准，不宣称授权 |
| 不过全额退款 | mid | 不过退款 | 退款条件须逐条写明，不作招生承诺 |

## 三、怎么用

在支持本技能引擎的工作台里选中「宣传合规自查」，把文案粘进 `text` 字段即可；或直接对智能体说：

- 「帮我看看这段招生文案有没有违禁词。」
- 「这句话能不能写：……」
- 「给我把这段直播话术逐句过一遍，标出风险等级。」

## 四、边界（务必先读）

- **只标风险，不给「能发」结论**；逐句扫描未命中，**不等于可以发布**。
- 最终口径**以市场监督管理部门与平台规则为准**。
- **不替代法律意见**；涉及行政处罚、诉讼或重大对外发布时，须咨询执业律师。
- 词表与模式是通用检测数据，不覆盖全部行业、地方性规定与平台细则。
- 只读、不联网、不写文件；不改写、不代发、不代提交。

## 五、文件清单

```
compliance-copy/
├── SKILL.md                 # 唯一事实源（frontmatter + 七段正文）
├── VERSION                  # 1.0.0
├── CHANGELOG.md
├── README.md
├── LICENSE                  # MIT
└── references/
    ├── engine.json          # {"engine":"compliance","rules":"rules.json"}
    ├── rules.json           # 业务规则唯一事实源（words / patterns / 公共字段）
    ├── 口径来源.md           # 违禁词依据与逐条对应（公开法规与平台规则）
    └── 人工把关点.md         # 机器不代办的步骤
```

## 六、改规则怎么改

- 词表与模式**只改** `references/rules.json`；改内容即升版本，同步改 `VERSION` 与 `CHANGELOG.md`。
- `engine.json` 的 `rules` 只能是 `references/` 下的文件名，不得带路径分隔符或 `..`。
