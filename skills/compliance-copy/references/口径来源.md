# 口径来源 · compliance-copy

> 本文件说明 `rules.json` 里风险词表与风险模式的**公开依据与来源边界**。
> 一句话：**全部来自公开法律与平台规则的通行口径，不引用任何内网文件、内部资料或个案结论。**

## 一、上位依据（公开）

| 依据 | 与本技能相关的主要口径 |
|---|---|
| 《中华人民共和国广告法》 | 广告不得含有虚假或引人误解的内容；不得对升学、通过考试、获得学位学历或合格证书，以及对教育、培训的效果作出明示或暗示的保证性承诺；不得使用「国家级」「最高级」「最佳」等绝对化用语（法定例外情形除外）。 |
| 《中华人民共和国反不正当竞争法》 | 经营者不得对其商品的性能、功能、质量、销售状况、用户评价、曾获荣誉等作虚假或引人误解的商业宣传，欺骗、误导消费者。 |
| 平台公开规则 | 各内容与交易平台的广告审核规范、违规营销话术清单、直播与信息流投放规则，均在其**官方规则中心公开展示**。 |

> 上述为**公开可查的通行口径**；条文以现行有效版本为准，具体适用由执法与司法机关判断。

## 三、来源边界（重要）

1. **只用公开来源**：法规条文、监管部门公开解读、平台官方规则中心；不使用任何内部文件、内网资料、客户材料或个案口径。
2. **不逐字抄录条文**：本表只作**主题方向**映射，用于解释「为什么这个词有风险」，不构成法条援引或法律意见。
3. **平台差异**：同一表述在不同平台的判定尺度可能不同，且平台规则会更新；发布前须回**平台当期规则原文**核对。
4. **地方与行业差异**：教育、职业培训、医疗、金融等行业另有专门规定，本技能为通用词表，不覆盖全部行业与地方性要求。
5. **机器只标不改**：命中的句子由**发布主体**决定如何改写与是否发布，机器不代拟、不代发。
6. **未命中不代表合规**：词表是有限集合，逐句扫描未命中仅表示「未命中已知风险项」，**不等于可以发布**。

## 四、词表维护

- 词表与模式的唯一事实源是 `references/rules.json`；本文件只作人读说明。
- 新增或调整风险项时，应能指向一条**公开依据或平台公开规则**；无法指向公开来源的，不进入词表。
- 词表更新即升版本，并同步 `VERSION` 与 `CHANGELOG.md`。
