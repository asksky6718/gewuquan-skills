# 发布对接

## 用途

把「一份已生成的课件」变成「可被别人访问/嵌入的播放形态」；**只到拿到可访问地址或课时创建结果为止。**

## 何时用

- 用户说：发布到 OSS / 同步网校课时 / 取 iframe / 把课件挂到网校
- 上游给到了：课件已在「我的课件」可见
- 课件不存在就停：先回 `skills/course-generate/SKILL.md`

## 输入

| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 课件 | 课堂 ID | 我的课件 | 停下先确认课件 |
| 目标通道 | 二选一或都要 | 用户 | 停下先问清「静态播放」还是「网校课时」 |
| 目标网校 / 课程 | 平台 ＋ courseId | 用户/网校侧 | 同步课时时缺就停 |
| 白名单域名 | 域名 | 网校侧 | iframe 嵌入前先确认域名已在防盗链白名单 |
| 管理会话 | cookie | `skills/admin-login/SKILL.md` | 后台操作前先登录 |

## 步骤

**A. 发布到 OSS（静态播放）**

1. 「我的课件」→ 该课堂的操作项选「发布到 OSS」（后台走**发布对接**页，静态播放器以插件形式提供）。→ 结果：出现发布任务与进度。
2. 等发布完成，取回 `liveUrl`。→ 结果：拿到一个可直接访问/分享的静态播放地址。
3. 核对防盗链：播放地址**仅白名单域名可嵌入**。→ 结果：明确「哪个域名能嵌」。

**B. 同步为网校课时**

4. 后台「发布对接」/课堂管理 → 「创建课时」：选**课堂** ＋ 目标网校的**课程（courseId）**。→ 结果：提交后返回任务标识（taskId）。
5. 核对发布结果：目标网校课程下应出现该课时。→ 结果：课时可见、可打开。

**C. iframe 嵌入**

6. 课堂管理提供「复制 iframe」；嵌入前确认**承载域名已加入防盗链白名单**。→ 结果：拿到 iframe 代码，且域名已白名单。

## 护栏

- **不擅自改目标网校的课程结构**（分区、排序、可见性）；只做「创建课时」这一动作。
- **不对播放地址有效期/稳定性作承诺**；地址属平台侧资产，变更以平台为准。
- 拿不准走哪条通道时，统一话术：**「要分享给外部人看＝发布到 OSS；要挂进已有网校课程＝同步课时」**。
- 对外可见内容须**先经负责人过目**；发布动作不可逆时**先确认再执行**。

## 产出物

- 一条发布结果记录（通道 / `liveUrl` 或 `taskId` / 目标课程 / 白名单状态）—— 交使用者确认；异常转 `skills/troubleshoot/SKILL.md`。
