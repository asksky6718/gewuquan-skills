# 供应商与模型

## 用途

把后台「系统设置」里的**能力供应商**配到「连接测试通过且跨刷新留存」；并给出**插件与模型清单**的读法。**不代填任何 API Key。**

## 何时用

- 用户说：配供应商 / 配视频生成 / 换模型 / 看看模型清单 / 连接测试失败
- 上游给到了：已登录后台 ＋ 具备系统设置权限
- 未登录就停：先回 `skills/admin-login/SKILL.md`

## 输入

| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 管理会话 | cookie | `skills/admin-login/SKILL.md` | 先登录 |
| 供应商凭据（API Key 等） | 密钥串 | **使用者本人写入** | **缺就停**；技能不代填、不代转述 |
| 目标供应商与模型 | 名称 | 用户 | 停下先问清「配哪一类能力、用哪个供应商」 |

## 步骤

1. 进入 `/admin` → **系统运维 → 系统设置**。→ 结果：看到供应商分类列表。
2. **按能力分类逐项看**（实测后台至少有这些分类位）：**视频生成 / 图像生成 / 语音合成 / 语音识别 / 文档解析 / 网络搜索**。→ 结果：明确要配的是哪一类。
3. 选定供应商，填 **Base URL** 与**模型**，并由**使用者本人**写入 **API Key**。→ 结果：表单字段齐全。
4. 点**「连接测试」**。→ 结果：成功时出现成功提示（如「视频服务连接成功」）；失败时**如实记错误原文**，不猜。
5. **保存并跨刷新核对**：保存后**刷新页面**再回看，确认配置仍在。→ 结果：配置持久，不是前端缓存假象。
6. 读清单：
   - **模型清单**：后台「模型管理」看各模型健康与默认模型；可切换默认模型。
   - **插件清单**：后台「发布对接」/插件相关页看已装插件（如静态播放器插件）。
   → 结果：拿到模型/插件原始清单。

## 已知实例（示例，非唯一）

| 能力 | 供应商 | Base URL | 模型 | 状态口径 |
|---|---|---|---|---|
| 视频生成 | 阿里云百炼 | `https://dashscope.aliyuncs.com` | `happyhorse-1.0-t2v` | 连接测试通过即配好 |

> 其余视频供应商位（如 Seedance / 可灵 / Veo / Sora / MiniMax 等）与其它能力分类**均可为空**；**以控制台实际下拉为准，不要凭本表假定**。

## 护栏

- **不代填、不代存、不代打印 API Key**；Key 只由使用者从凭据保险库写入。
- **连接测试未通过＝没配好**：不得跳过测试直接保存并声称可用。
- 拿不准是否生效时，统一话术：**「保存后刷新页面仍在，才算真的配上」**。
- 改动系统设置属**影响在跑系统**的动作 → 动前先确认影响面；有回滚点更好。

## 产出物

- 一份「供应商配置核对表」（能力 / 供应商 / 模型 / 连接测试 / 跨刷新留存）—— 交使用者确认；失败项转 `skills/troubleshoot/SKILL.md`。
