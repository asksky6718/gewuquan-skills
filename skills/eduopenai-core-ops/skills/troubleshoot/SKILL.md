# 排障

## 用途

把「一个具体现象」变成「一条可复现的处置结论」；**只报事实与实跑结果，不猜根因。**

## 何时用

- 用户说：后台打不开 / 登录失败 / 生成失败 / 剩余 0 / 发布失败 / 连接测试失败
- 上游给到了：**现象原话** ＋ 时间点（＋当前步骤）
- **缺现象原话就停**：先问清「点了什么、期待什么、实际什么」

## 输入

| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 现象原话 | 文本 | 用户 | 停下先问 |
| 复现步骤 | 文本 | 用户/现场 | 停下先问 |
| 返回状态 / 响应体 / 截图 | 文本/图 | 用户 | 停下先要 |
| 管理会话 | cookie | 使用者 | 需要后台核对的先登录 |

## 步骤

1. 对照清单初步归口（见下）→ 结果：得到候选处置项。
2. 逐项实跑验证 → 结果：每项标注「已消 / 未消 / 不适用」。
3. 需要接口判定的做只读请求（见 `references/endpoints.md`）→ 结果：拿到状态码与响应体原文。
4. 仍无法归口时，**如实记「未复现/未归口」**，列出还需哪些原始输出。→ 结果：一条不含猜测的结论。

| 现象 | 处置 |
|---|---|
| 访问 `/admin` 得到 **401** | 正常行为：未登录受保护路径返回 401 → 先走登录（`../admin-login/SKILL.md`） |
| 登录返回 **401 `INVALID_CREDENTIALS`** | 口令错或已轮换 → 重新从凭据库取；**禁止尝试猜测** |
| 登录页「管理员账号」栏不知填什么 | 该栏可留空/忽略，**以管理口令为准** |
| 游客点「进入课堂」生成失败 | **未登录**所致 → 先登录；生成功能需登录并占用配额 |
| 提示「剩余 0」 | 配额用尽 → 「我的课件」→「申请 Token」追加，管理员审核发放 |
| 生成后刷新课件不见了 | 已自动保存到「我的课件」；从列表重新进入，**不重复扣配额** |
| 反复生成不满意 | 每次重生成**会再消耗配额** → 先与使用者确认再重来 |
| 发布到 OSS 后无法嵌入 | 播放地址**仅白名单域名可嵌入** → 把承载域名加入防盗链白名单 |
| 同步网校课时无结果 | 核对是否返回任务标识（taskId）＋ 目标 courseId 是否正确 |
| 供应商「连接测试」失败 | 记错误原文；核对 Base URL / 模型名 / Key 是否由使用者正确写入；**不猜** |
| 配好刷新后配置消失 | 未真正保存 → 重做「保存 → 刷新 → 回看」三步 |

## 护栏

- **只报事实**：不给根因猜测，未复现时不给「应该是…」的结论。
- **不动生产数据**：不做数据库写操作、不批量重发、不改未点名的配置。
- 拿不准时统一话术：**「未复现，需要原始输出（状态码 / 响应体 / 截图）才能归口」**。
- 同一动作连续两次失败即停，转人工。

## 产出物

- 一份「现象—处置—实跑结果」三段式记录 —— 交使用者确认；涉及平台缺陷时转需求/缺陷登记。
