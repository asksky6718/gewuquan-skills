# 生成课件

## 用途

把「一个课程主题 ＋ 目标人群」变成一份**已落库的互动课堂课件**；**只到课件在「我的课件」可见为止，不代做内容合规背书。**

## 何时用

- 用户说：生成课件 / 出个课件 / 做个互动课堂 / 按主题生成课程
- 上游给到了：**课程主题**（＋目标人群、关键知识点更佳）
- **主题不明就停**：先问清「给谁学、学什么、到什么程度」

## 输入

| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 课程主题 | 文本 | 用户 | 停下先要 |
| 目标人群 | 文本 | 用户 | 缺失时按「成人职业教育学习者」假定，并在产出物标注 |
| 关键知识点 | 文本/清单 | 用户 | 可缺省，由平台提炼 |
| 已登录的生成端账号 | 会话 | 使用者 | 未登录则先解决登录；游客不可用生成功能 |
| 配额 | 数值 | 我的课件页显示 | 为 0 时先申请/追加配额 |

## 步骤

1. 登录生成端 `https://www.eduopenai.com/`（未登录会提示「请先登录后使用生成功能（Token 配额）」）。→ 结果：右上角显示已登录。
2. 在首页输入框填入**主题 / 大纲 / 学习目标**（越具体质量越高）。→ 结果：输入框回显。
3. 点「进入课堂」→ 平台按**碎片化生成**工作：先提炼**知识点清单**并独立校验，再**逐知识点生成**课堂内容，最后组合成完整课程。→ 结果：出现分阶段进度提示。
4. 等待生成完成（视复杂度通常数分钟）；分阶段可见「生成课程大纲 → 生成课堂角色 → 生成页面内容」。→ 结果：进入课堂预览页。
5. 在课堂页审阅：角色、页面内容、交互（测验/PBL）。→ 结果：能逐页翻看。
6. 确认已落库：课件自动保存到「我的课件」。→ 结果：列表中出现该课件；**刷新不重复扣配额**。
7. 记录消耗：查看配额余量变化。→ 结果：拿到本课前后的配额读数。

## 护栏

- **不一次生成长课时**：平台机制是按知识点分次生成（如 8 课时＝累计 8 个知识点分次生成）；不要试图绕过。
- **不代做内容合规判定**：生成内容是否可用、是否对外，须由负责人判断；**生成结果不直接对外发布**。
- 拿不准输入写法时，统一话术：**「按『主题 ＋ 目标人群 ＋ 关键知识点』三段式给，越具体生成越准」**。
- 重复生成会**再消耗配额** → 每次重新生成前先与使用者确认。

## 产出物

- 一份课件（课堂 ID / 标题 / 阶段产物）＋ 配额读数 —— 交使用者确认；确认后转 `skills/publish-integration/SKILL.md`。
