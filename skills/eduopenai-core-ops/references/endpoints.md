# 端点、鉴权与响应形态（实测）

> 全部为 **2026-10-13 实测**；接口若变更，以**实机复跑**为准并回填本文件。
> 基址 ＝ `https://www.eduopenai.com`。

## 一、入口与可达性

| 路径 | 方法 | 未登录实测 | 说明 |
|---|---|---|---|
| `/` | GET | **200** | 生成端（用户面） |
| `/admin` | GET | **401** | 管理后台；服务端鉴权，未登录直接 401 |
| `/admin-login` | GET | **200** | 登录页 |

## 二、登录接口

| 项 | 值 |
|---|---|
| 端点 | `POST /api/edu/v1/admin/login` |
| 请求体 | `{"code":"<管理口令>"}` |
| 成功 | 下发管理会话 cookie |
| 失败 | **HTTP 401**，响应体：`{"success":false,"errorCode":"INVALID_CREDENTIALS","error":"Invalid admin credentials"}` |

**要点**：
- 鉴权以 **`code`（管理口令）** 为准；登录页若另有「管理员账号」栏，**可留空/忽略**。
- 口令**不入技能正文、不入产出物、不入对话**；由使用者从凭据保险库取用。

## 三、响应体判读（排障用）

| 观察 | 含义 |
|---|---|
| `/admin` 返回 401（空体/跳转登录页） | **未登录** —— 正常行为，不是故障 |
| 登录接口 401 ＋ `errorCode=INVALID_CREDENTIALS` | **口令错误**或已轮换 |
| 登录接口 401 ＋ 其它 `errorCode` | 按 `errorCode` 原文归口，**不猜** |

## 四、管理后台主要功能位（模块名）

> 模块名以控制台实际导航为准；此处供定位用。

- **系统运维 → 系统设置**：能力供应商配置（视频生成 / 图像生成 / 语音合成 / 语音识别 / 文档解析 / 网络搜索）
- **发布对接**：发布到 OSS（静态播放器插件）／网校课时同步／iframe 嵌入
- **课堂管理 / 我的课件**：课件列表与发布操作
- **模型管理**：模型健康与默认模型切换
- **配额管理**：Token 申请审核、配额查看与回收
- **用户管理**：注册审核、重置口令、禁用/恢复账号

## 五、鉴权口径（进阶）

- 付费 LLM 接口（chat / pbl / quiz-grade / web-search / agent-edit）**均有登录 ＋ 配额闸门**。
- 对外 API 契约与「发布到网校」「其他网校域名接入」等，见平台**文档站**（`/docs`）。
