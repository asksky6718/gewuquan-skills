# 申报跟踪

## 用途

从"点提交"到"拿电子证书"，每一步的时间节点都不错过。

## 何时用

- "怎么提交""什么时候缴费""受理号是什么"；
- "结果在哪看""证书怎么下载"；
- 整批模式：全批节点提醒。

## 输入

```
评委会与申报窗口（政策卡）
系统账号状态（是否已用随申办 APP 注册）
受理号（如已分配）
```

## 步骤

1. **系统入口与登录**（★关键差异）：
   - 入口：`http://www.rsj.sh.gov.cn/zcps/zcpssb/index`（上海市职称服务系统）；
   - **首次登录必须用手机「随申办 APP」注册用户信息**——**不是账号密码登录**；
   - 因此**不能无人值守自动申报**，提交动作必须本人在场。

2. **填报与提交**：
   - 按要求填写基本资料，**尽可能填完整**（空缺会被视为"无"）；
   - 上传全部附件（彩色扫描）；
   - 检查无误 → 点击提交 → 打印申报表；
   - 申报表交单位审核签字盖章 → 上传至"单位意见栏"。

3. **盯退回窗口**：
   - 评委会形式审核，**退回后须在 5 个工作日内修改并再次提交**，逾期视为放弃；
   - 建议**关闭手机短信过滤功能**，否则收不到通知。

4. **受理与缴费**：
   - 初审通过后分配**受理号**（短信通知）；
   - 缴费方式按评委会：AI 专业**未开通网上缴费**，须**银行转账**——备注栏必须写「**申报人姓名** + 年度 + 专业 + 中级工程师评审费」；**代缴时也必须写申报人姓名，不写代缴人**；
   - 缴费后**截屏、打印付款凭证**保留；发票发送到系统登记的电子邮箱（务必填准）；
   - **当年度未通过不退费**。

5. **纸质材料与答辩**：
   - 纸质材料报送时间以**平台短信**通知为准；
   - 部分人员需**面试答辩**，**无故缺席视为当年评审不通过**。

6. **结果与拿证**：
   - 评审结果在职称服务系统**公示 5 个工作日**；
   - 无异议后由市人社局统一制作**电子资格证书**，在申报网页查看、下载；
   - 通过人员通知文件在评委会指定网站下载（如经信委系统 `www.sheitc.org.cn`，路径：首页"项目服务"—人才服务—点击职称发文名称—下载附件），**文件密码＝职称证书号前八位**；
   - 彩色打印后**交给所在单位归档**，作为单位聘用的依据。

## 护栏

- **提交、缴费、确认放弃类动作不可逆** → 执行前必须列出对象、影响、风险，**经人工确认后再做**；
- 不代客户操作其账号；账号与短信验证码属个人凭据，**不得索取、不得留存、不得写入任何文件**；
- 网上材料是**最终评审依据**，纸质与网上不一致时以网上为准；
- 5 个工作日退回窗口、答辩缺席规则，必须提前告知客户。
