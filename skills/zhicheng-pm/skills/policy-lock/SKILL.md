# 政策锁定

## 用途

**一个人一套标准**。锁定评委会，抄下当年那套硬参数——这是后面所有环节的依据。

## 何时用

- 确定目标专业/方向后（"我要报人工智能方向"）；
- 有人说"我记得是 90 学时"——需要用原文纠正时；
- 批次建立时（锁定整批的评委会与窗口）。

## 输入

```
目标专业 / 专业方向（如：人工智能、数字技术-大数据、密码工程）
申报人工作单位所属系统（决定归口）
申报年度
```

## 步骤

1. **定评委会**：按专业方向在 `政策库/上海中级职称评委会总表.md` 查候选，再用 `政策库/评委会政策差异对照.md` 比对；
2. **打开当年通知原文**（★必须）：点总表里的原链接，或从栏目首页 `rsj.sh.gov.cn/tzjjszwpstz_17413/index.html` 检索标题；
3. **抄四件事**（照抄，不推断）：

| 参数 | 抄什么 |
|---|---|
| 继续教育 | 总学时 + 公需/专业拆分 + 各自报名平台 |
| 论文/业绩 | 三选一还是凑多项？字数要求？独撰还是可合作？ |
| 申报窗口 | 网上注册填报起止日 + 纸质材料时间 |
| 评审费 | 金额 + 缴费方式（网上/转账）+ 退款规则 |

4. **补充三个易漏参数**：是否需要答辩、报送地点、联系人电话；
5. **回填知识库**：若是新评委会，在 `政策库/` 新建页面并回填总表；
6. **写台账**：评委会、窗口、风险截止日。

## 护栏

- **不回原文核，不给结论**。知识库里的学时/费用是抓取的结果，只作线索；
- **不要跨评委会套用**：AI 专业 90 学时、数字技术第三 75 学时，套错就是白做；
- 库里的年份数据只能推断趋势，**必须以当年通知为准**；
- 通知原文里若有"从未委托任何单位或个人代办"的申明，不得对外表述为合作关系。
