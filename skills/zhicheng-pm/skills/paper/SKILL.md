# 论文 · 技术总结

## 用途

定清"这个人该交什么、写什么方向、附件怎么齐"。

## 何时用

- "论文写什么方向好"；
- "技术总结和论文选哪个"；
- 交稿前核对附件与查重。

## 输入

```
评委会论文/业绩要求（从政策卡取）
本人项目与技术成果
已有论文（是否已发表、刊物、作者位次、字数）
```

## 步骤

1. **取要求**（三选一还是凑多项？字数？是否必须独撰？）：

| 评委会类型 | 要求形态 |
|---|---|
| 论文型（如 AI 专业） | 三选一：独立撰写论文 1 篇 / 一作公开发表论文 1 篇（合作原则上不超 3 人）/ 独立撰写项目技术总结 1 篇 |
| 业绩型（如数字技术第三） | 业绩成果 **2 项以上**，且 1–3 类含 1 项、4–8 类含 1 项 |

2. **选路线**：有已发表论文 → 优先用；没有 → 走**项目技术总结**（成本最低，但**必须单位出"独立撰写"证明**）；
3. **给提纲**（项目技术总结）：
   ```
   项目背景与定位 → 本人承担的岗位职责 → 采用的技术方案 → 解决的技术难题
   → 本人起到的创造性作用与贡献 → 项目水平与成效
   ```
   字数按评委会要求（数字技术第三约 **2000 字**；其他从原文取）；
4. **查重提醒**：
   - 部分评委会**会对论文做重合度检查**；
   - 项目技术总结常要求附**当月度查重报告（全文注释版本）**；
   - 已自行查重的可随论文一并提交；
   - **学术造假一票否决**，不予进入评审程序；
5. **核附件**：每篇论文/专著/技术总结**各传一个附件**；论文附件＝期刊封面 + 目录页 + 全文；外文附中文翻译；专著＝封面 + 目录页 + 封底；
6. **定主送**：提交 2 篇以上时，**须指定 1 篇为主送论文**。

## 护栏

- **不代写、不代发、不伪造发表**；
- **不可作为送审论文**的：毕业/学位论文（含在职学习的学位论文）、项目（工程）设计说明书、产品说明书、可行性研究、立项申请、验收报告、测试报告、产品标准、专利申请报告；
- 项目技术总结**只能以其中 1 个项目撰写**，且该项目须在系统"项目/课题情况"栏登记并传佐证；
- 在职学习取得的学位论文不能作为职称申报论文。

## 产出物

- 论文/技术总结**提纲**（含字数目标与章节配比）；
- **附件齐备清单**（封面/目录/全文/翻译/查重报告）；
- 主送论文指定建议。
