# 单位材料

## 用途

把要**单位盖章**的东西一次办齐，少跑腿、不返工。

## 何时用

- "单位要盖哪些章""考核意见表怎么写"；
- "公示怎么弄""要公示几天"；
- 截止日前催单位走流程。

## 输入

```
申报人 / 工作单位 / 部门及职务
项目清单（用于项目证明）
近三年年度考核结果
单位人事联系人
公示安排（拟公示起止日）
```

## 步骤

1. **列盖章清单**（这是最容易漏的一环）：

| 材料 | 谁签章 | 备注 |
|---|---|---|
| 项目（课题）参与情况证明 | 单位公章 + **负责人签章** | 一项目一页 |
| 单位考核评价意见表 | **单位公章**（近三年各盖一格）+ **填表人签名** + 部门及电话 + 填表日期 | 四样齐全 |
| 中级职称评审申报表 | 单位审核意见栏签字盖章 | **系统生成后**才盖章 |
| 专业技术职务聘任表 | 单位盖章 | 资历起算的唯一凭据 |

2. **给考核意见表草稿**（三段评价 + 公示勾选）：
   ```
   专业理论与技术知识      ：掌握的专业理论与技术栈、方法论
   独立工作及解决技术问题  ：结合实际项目写解决过的问题
   职业道德和工作态度      ：职业操守、协作、合规表现
   单位是否公示且无异议    ：☐是 ☐否（★硬指标）
   近三年度考核评价结果    ：三个年度各一格，各盖公章
   ```
3. **盯公示**：单位须对申报情况**公示不少于 5 个工作日**，公示情况由单位人事部门填在申报表"单位意见"栏，**注明公示期并核实盖章**；
4. **核近三年考核**：须为**合格及以上**（缺年度的要补）；
5. **排期**：把"送单位 → 内部审批 → 盖章 → 取回"的时间算进去，**截止日前两周就启动**。

## 护栏

- **不代签、不代盖章**，起草稿可以，签字盖章必须单位本人完成；
- 公示期不足 5 个工作日＝无效；
- 考核意见表落款的"部门及电话"要能打通，评委会可能核实；
- 聘任表与聘任文件二者其一，**没有就不算资历起点**。

## 产出物

- 单位考核评价意见表**填写草稿**；
- 项目参与证明**盖章版待办清单**；
- 公示时间安排建议（含截止倒推）。
