# 建档与资格

## 用途

把一个人的基础信息收全，一次给出**能不能报、最早哪年能报**的结论。

## 何时用

- 新客户进来，问"我够不够条件"；
- 已申报的人补充材料（"上一年报过没""社保够不够""居住证有没有"）。

## 输入

必收字段（缺一不可，缺了先问，不要猜）：

```
姓名 / 学历（层次·专业·毕业时间·全日制还是非全日制）
现工作单位 / 参加工作起始时间
现职称（有/无） / 助理工程师聘任日期（有/无）
是否本市户籍 / 是否持有效居住证 / 近2年本市社保累计月数
上一年度是否参加过本市工程师职称评审
```

## 步骤

1. **收信息**：按上面清单逐项问清，一次性问完，不要挤牙膏；
2. **理工类判定**（★硬门槛，先做）：
   - 通过：计算机科学与技术、计算机应用技术、软件工程、人工智能、自动化、机械工程、电子信息等；
   - **不通过**：工商管理、人力资源、会计学等管理/财经类。
   - **不通过则停止**，直接告诉客户这条路不通，不要继续算年限浪费时间。
3. **算助理工程师最早聘任时间**：
   ```
   理工类本科：毕业满 1 年
   理工类大专：毕业满 3 年
   理工类中专：毕业满 1 年聘技术员 → 技术员满 4 年聘助理工程师
   ```
4. **算中级最早申报**：`助理工程师聘任日 + 4 年`（理工类硕士为 +2 年，博士考核合格可直接申报）；
5. **资历截止日**：上半年填报算到**当年 6 月 30 日**；下半年填报算到**当年 12 月 31 日**；
6. **核入口条件**（满足其一）：本市户籍 / 有效期内《上海市居住证》 / **近 2 年内本市累计缴社保满 12 个月**；
7. **核排除项**：当年度退休者不能报；**上一年度评审未通过者当年不能再报**（有省部级以上奖项或独立论著除外）；
8. **写台账**：把结论写进批次台账对应行。

## 护栏

- **非理工类学历不通过**，这是硬门槛，不要因为"客户年限很长"就放行；
- **助理工程师聘任必须有凭证**（单位聘任文件或市人社局统一印制的《专业技术职务聘任表》），口头说有不算；
- 不替客户编造学历、聘任日期、社保记录；
- 「先聘后学」的人注意：先评聘助理工程师、后取得学历的，须**取得学历且工作满一年**才能按后取得学历申报；
- 需扣除的时段：待岗待聘、长病假、参加全日制教育等不在岗时间。

## 产出物

一人一份**资格结论卡**：

```
【姓名/代号】          【结论：可申报 / 条件不足 / 不适用】
用于申报的学历：专科(理工类·计算机应用技术·2023-01·非全日制)
理工类判定：       通过（依据：计算机应用技术属理工类）
助理工程师聘任：   2026-01（依据：聘任表）
最早可申报年度：   2030 年（聘任 +4 年）
入口条件：         近2年社保累计 14 个月，通过
排除项：           上一年度未参加过 → 无阻碍
下一步：           进入「政策锁定」
```

同时写进台账行。
