# 打穿主线

## 用途

把**一个人**从"够不够格"一路推到"拿证"。这是整个技能包的地基——
批量管理层不重新判断，只把多张进度卡摞起来汇总。

## 视角中立

对面是**申报人本人**还是**项目经理代跑**，本技能不关心，也不去猜。
只问一件事：**现在办谁**。

- 用户说"我要报" → 办的人就是他本人，口气按"你"；
- 用户说"帮张三办" → 办的人是张三，口气按"张三"；
- 没说办谁 → 问一句，不要默认。

## 何时用

- "帮张三从头走一遍" / "我要报职称，从哪开始"；
- "下一步干什么" / "继续办张三" / "接着走"；
- "现在到哪一步了"。

## 输入

```
办谁（姓名，或"本人"）
```

进度卡存在则读进度卡，没有就新建，从第 1 道门起。

## 步骤

**一次只推进一步。** 打穿不是一口气跑完——中间有挂起（等人取证、等窗口开）和人工点（扫码、缴费、盖章），
必须停下来等人。跑到底的冲动是错的。

1. **确认办谁**，读或建进度卡；
2. **看当前在第几道门**，按 `references/执行主线.md` 里那道门的"做什么"执行；
3. **判定过没过**：
   - 过 → 往进度卡写"已完成门"，进入下一道门；
   - 不过 → 按那道门的"过不了怎么办"分流：**终止 / 挂起 / 退回上一道门**；
4. **报进度卡**（格式见 `references/执行主线.md` 开头），并说清下一步；
5. **停**，等反馈。不要自作主张往下推。

## 挂起怎么管

挂起不是放着不管。挂起时必须登记三件事：

```
挂起原因：    等本人给助理工程师聘任表
挂起归属：    本人
解除条件：    拿到聘任表扫描件
```

下次用户回来，先查挂起原因解除了没有，解除就继续，没解除就提醒，不重复问。

## 碰到人工点

走到第 5 道门（申报执行）时，按 `references/人工把关点.md` 交接：
先把填写手册、上传件清单、提交前自检表全部备好，**一次交完**，
再让本人上手。不要挤牙膏式地一次给一栏。

## 护栏

- **顺序不可跳**：第 1 道门没过就查政策、没定评委会就查学时，都是错的。
  详见 `references/执行主线.md`「顺序为什么不能跳」；
- **不替人编**：学历、聘任日期、项目经历、社保记录，一律以凭证为准，没有就说没有；
- **不承诺结果**：不做"包过""有内部关系"之类的表述，通知原文明确评委会从未委托任何代办；
- **单点答疑不强制推进**：用户只是来问一句"人工智能要多少学时"，答完就收，
  不写进度卡、不追问"要不要现在建档"；
- **实名资料不进共享知识库**：进度卡与台账放工作区。

## 产出物

**进度卡**（每过一道门更新一次）：

```
【办谁】          张三
当前门：         第 3 道 · 锁政策
开始日期：       2026-10-07
本门停留：       3 天
卡在谁手上：     本人（等聘任表）
下一步动作：     打开 2026 年通知原文，抄学时与窗口
已完成门：       1 资格（通过）→ 2 定评委会（人工智能中评委）
```

走完第 5 道门后，进度卡收口为**结案卡**：受理号、缴费凭证、报送回执、答辩结果、证书下载。
