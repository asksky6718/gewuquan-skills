# 批次台账字段定义

> 台账是项目经理的**唯一进度表**，每个环节干完都往里写。
> 完整说明与 CSV 模板见知识库 `台账/批次台账模板.md`。

## 表头（批次级）

| 字段 | 填法 |
|---|---|
| 批次名称 | 2027 上半年·人工智能中级 |
| 申报年度 | 2027 |
| 目标评委会 | 一个批次尽量只放同一评委会 |
| 网上申报窗口 | 起 — 止（原文抄） |
| 资历截止日 | 上半年 6/30 / 下半年 12/31 |
| 批复方式 | 电子证书 |

## 逐人字段

**基础段**：编号｜姓名/代号｜联系方式｜目标专业｜锁定评委会｜入口条件

**资格段**：学历（申报用）｜全日制｜毕业时间｜**理工类判定**｜助理工程师聘任日｜**最早可申报年度**

**进度段**：公需已修/应修｜专业已修/应修｜论文/技术总结状态｜项目证明｜单位考核｜公示状态｜申报表

**跟踪段**：**当前环节**｜**卡点**｜**下一步**｜责任人｜**风险截止日**｜最后更新

## 「当前环节」只能用这九个值

```
1 建档与资格   2 政策锁定   3 继续教育   4 业绩提炼   5 论文·技术总结
6 单位材料     7 材料成册   8 申报跟踪   已完成 / 已放弃
```

## 「下一步」的写法要求

必须能落到人、落到日期。

- ✗ 不合格："推进材料""跟进一下"
- ✓ 合格："张三 10/15 前收齐第二段劳动合同"

## 三种看法

| 视角 | 怎么筛 | 回答什么 |
|---|---|---|
| 卡点视图 | 按"当前环节"分组 | 谁停着不动、哪一环堵人最多 |
| 催办视图 | 按"风险截止日"升序 | 今天该找谁 |
| 齐备度视图 | 数"申报表=已盖章" | 这批能交几个 |

## 三条硬规矩

1. **台账放工作区，不放共享知识库**（含联系方式，属个人信息）；
2. **每改一次更新"最后更新"**，超过 14 天没动的行自动进催办视图；
3. **"下一步"必须落到人**。
