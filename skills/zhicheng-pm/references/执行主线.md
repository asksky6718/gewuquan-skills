# 执行主线：五道门

一个人的申报从进门到拿证，只走一条线。五道门**顺序推进，不可跳过**。
每道门写死四件事：进门要什么、出门交什么、过不了怎么办、谁动手。

## 门与门的接口：进度卡

每道门出门都往同一张**进度卡**上写。进度卡是单人层与批量层之间唯一的接口——
批量层不重新判断，只把 N 张进度卡摞起来。

```
【办谁】          张三（或本人）
当前门：         第 3 道 · 锁政策
开始日期：       2026-10-07
本门停留：       3 天（超过 7 天要报异常）
卡在谁手上：     本人（等他给聘任表）
下一步动作：     打开 2026 年通知原文，抄学时与窗口
已完成门：       1 资格（通过）→ 2 定评委会（人工智能中评委）
```

---

## 第 1 道 · 资格门

**进门要什么**：申报人基础信息，八项缺一不可（见 `skills/batch-intake/SKILL.md` 输入清单）。

**做什么**：理工类判定 → 助理工程师聘任时间 → 中级最早申报年度 → 入口条件 → 排除项。

**出门交什么**：资格结论卡，结论只有三种——`可申报` / `条件不足` / `不适用`。

**过不了怎么办**（按原因分流，不要一律说"不行"）：

| 卡住的原因 | 处置 | 后续 |
|---|---|---|
| 非理工类学历 | **终止这条线** | 给出路：用本人手上的理工类学历申报 / 先取得理工类学历 / 改走非工程系列 |
| 年限差几个月 | **挂起** | 挂到「最早可申报年度」，登记日历，到点重跑 |
| 助理工程师无凭证 | **挂起** | 等聘任表或市人社局《专业技术职务聘任表》，口头说有不算 |
| 入口条件不满足 | **挂起** | 算清还差几个月社保、或先办居住证 |
| 上年度评审未通过 | **当年终止** | 次年再来（有省部级奖项或独立论著除外） |
| 当年度退休 | **终止** | 无解，明确告知 |

**谁动手**：机器判，人提供凭证。不替人编学历、编聘任日期、编社保。

---

## 第 2 道 · 定评委会与专业

**进门要什么**：第 1 道门的资格结论卡（必须 `可申报`）+ 工作单位 + 岗位方向 + 学历专业。

**做什么**：按**单位归口**与**岗位方向**在 `政策库/上海中级职称评委会总表.md` 里筛候选，
再用 `政策库/评委会政策差异对照.md` 比对，给出**最多三个候选**并说明各自的代价。

**出门交什么**：评委会选定卡（评委会全称 + 学科组/方向 + 选定理由 + 被否掉的候选及原因）。

**过不了怎么办**：

- 候选为空 → 退回第 1 道门核专业与单位行业归属；
- 多个候选难分 → **交给本人拍板**，机器只负责把代价讲清楚，不替人选。

**为什么必须人拍板**：评委会一锁定，学时、论文、费用、窗口、报送地点全跟它走。
选错等于后面全部重做。

**谁动手**：机器推荐，人确认。

---

## 第 3 道 · 锁当年政策

**进门要什么**：第 2 道门的评委会选定卡 + 申报年度。

**做什么**：打开**当年**通知原文，照抄四件事（继续教育、论文业绩、申报窗口、评审费），
再补三个易漏参数（是否答辩、报送地点、联系人电话）。

**出门交什么**：政策卡（含原文链接与核验日期）。

**过不了怎么办**：

- 当年通知未发布 → **挂起**，可用上一年作参考，但必须标注「待核」，通知一发布立刻重跑；
- 通知已过期（窗口已关）→ 登记次年窗口，挂起。

**硬红线**：**不回原文核，不给结论。** 知识库里的数据是线索，不是依据。

**谁动手**：机器联网核，附原文链接。

---

## 第 4 道 · 补齐缺口

**进门要什么**：第 3 道门的政策卡。

**做什么**：拿政策卡逐项对账，把缺口列成清单，逐项消掉。四个子动作**可并行**：

| 子动作 | 入口 | 消掉的标志 |
|---|---|---|
| 继续教育学时 | `skills/edu-hours/SKILL.md` | 公需与专业科目分别达标，有平台记录 |
| 业绩提炼 | `skills/achievement/SKILL.md` | 项目经历已改写成申报语言，有佐证 |
| 论文·技术总结 | `skills/paper/SKILL.md` | 定稿完成，查重达标 |
| 单位材料 | `skills/unit-material/SKILL.md` | 证明与考核意见表拿到手，盖章完成 |

**出门交什么**：缺口清零 + `skills/assemble/SKILL.md` 的成册清单逐项打勾。

**过不了怎么办**：缺件一律进**缺件清单**，每一项都要标「卡在谁手上」：

- `本人`（他要去做，如上课、写论文）
- `单位`（要单位出证明、盖章、公示）
- `第三方`（要等平台出成绩、等期刊出刊）
- `政策`（要等窗口、等通知发布）

标不出归属的缺件，等于没催。

**谁动手**：机器起草与核对，人取证、单位盖章。

---

## 第 5 道 · 申报执行

**进门要什么**：材料已齐 + 申报窗口已开。

**做什么**：先出**逐栏填写手册**（每一栏填什么、上传哪个文件、文件名怎么起），
再由本人在系统上操作，机器只做核对与提醒。

**出门交什么**：受理号 → 缴费凭证 → 纸质报送回执 → 答辩安排 → 评审结果 → 电子证书。

**过不了怎么办**：

- 被退回 → **5 个工作日内**改完再提交，逾期视为放弃（这条必须提前告知）；
- 缺席答辩 → 视为当年不通过。

**谁动手**：**必须本人在场。** 扫码登录、提交、缴费、盖章、签字、报送、答辩，一个都不能代劳。
详见 `references/人工把关点.md`。

## 三种用法（同一套门，三种叫法）

| 用法 | 用户这样说 | 行为 |
|---|---|---|
| **打穿模式** | "帮张三从头走到尾" / "我要报职称，从哪开始" | 从第 1 道门起一路推，每过一道门报一次进度卡 |
| **单点模式** | "人工智能要多少学时" / "这个专业要答辩吗" | 只回答问题，**不推进主线、不写进度卡** |
| **批量模式** | "这批人现在都到哪一步了" | 把 N 张进度卡摞成台账，见 `references/台账字段.md` |

**单点模式不要强行拉人走流程**：用户只是来问一句，答完就收，不追问"那你要不要现在建档"。

## 顺序为什么不能跳

- 没过资格门就查政策 → 可能在给一个根本报不了的人算学时；
- 没定评委会就查学时 → AI 专业 90、数字技术第三 75，套错全白做；
- 没锁政策就补材料 → 不知道要补几篇论文、多少学时；
- 材料没齐就提交 → 退回重来，白等一轮窗口。

只有一种例外：**单点答疑**。答可以答，但不算推进，不写进度卡。
