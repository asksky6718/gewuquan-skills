# 人工把关点

目标：**能机器做的全交给机器，机器做不了的列清楚、提前准备好、一次交接完**。
不搞"我来试试能不能自动化"——试不出来的就老实标成人工，别给人虚假期待。

## 一、完全不用人操心的（机器全包）

| 事项 | 机器做到哪一步 |
|---|---|
| 政策检索 | 联网打开当年通知原文，逐条抄出参数并附链接 |
| 资格判定 | 理工类、年限、入口条件、排除项，一次算清出结论卡 |
| 评委会推荐 | 给出最多三个候选，讲清各自代价 |
| 学时计算 | 按政策卡的公需/专业拆分，算缺口，排到月 |
| 业绩改写 | 把岗位经历改写成申报语言，出草稿 |
| 论文提纲 | 定方向、给提纲、给查重建议 |
| 材料核对 | 全套清单逐项打勾，缺件列出来并标归属 |
| 时间排期 | 窗口、退回窗口、缴费、报送、答辩、公示全排成表 |
| 填写手册 | 系统里每一栏填什么，预先算好，见第三节 |

## 二、必须本人上手的（七个，一个都不能少）

| # | 动作 | 为什么躲不掉 | 机器提前准备好什么 | 人做完回什么 |
|---|---|---|---|---|
| 1 | 随申办扫码登录 | 首次登录只认手机「随申办 APP」实人注册，**不是账号密码** | 入口网址 + 注册步骤 + 要准备的材料 | 一句"已注册" |
| 2 | 点「提交」 | 不可逆 | 逐栏填写手册 + 上传件清单 + 提交前自检表 | 提交时间 + 申报表打印件 |
| 3 | 缴费转账 | 花钱；AI 专业未开通网上缴费，须银行转账 | 金额、收款信息、**备注栏写法**（申报人姓名+年度+专业+中级工程师评审费）、发票邮箱 | 付款凭证截图 |
| 4 | 单位盖章 | 公章在单位手里 | 已填好的证明与考核意见表初稿 + 盖章位置标注 | 盖章件扫描 |
| 5 | 本人签字 | 代签违规 | 签字位置清单 | 签字件扫描 |
| 6 | 纸质材料报送 | 要跑现场 | 报送地点、时间、材料装订顺序、份数 | 报送回执 |
| 7 | 答辩出场 | 无故缺席视为当年不通过 | 答辩范围、常见问法、时间地点 | 结果 |

## 三、中间地带：逐栏填写手册

系统里几十个栏位，人一个个想很慢。**机器的活是把它预先算好**，
人登录后照着贴就行——这是真正省时间的地方。

手册格式（每一栏一行）：

```
栏位名        填什么                          从哪来
─────────────────────────────────────────────
姓名          张三                            本人确认
申报专业      人工智能（AI 赋能行业应用）       政策卡·学科组
学历          本科·计算机科学与技术·2019-07     资格结论卡
助理工程师聘任 2022-03                         聘任表
继续教育      公需 30 + 专业 60 = 90           平台记录截图
上传件 1      学历证书.pdf（彩色，≤2MB）        材料清单第 3 项
上传件 2      聘任表.pdf                       材料清单第 5 项
```

出手册时一并交代三件事：

- **空缺会被视为"无"**——能填的都填上，不要留空；
- 上传件一律**彩色扫描**，按清单里的文件名命名；
- 网上材料是**最终评审依据**，与纸质不一致时以网上为准。

## 四、交接纪律

- **账号、密码、短信验证码一律不索取、不留存、不写进任何文件**；
- 不代客户操作其账号；
- 提交、缴费、确认放弃类不可逆动作：执行前**必须列出对象、影响、风险**，经本人确认后再做；
- 提交后提醒**关闭手机短信过滤**，否则收不到退回与受理号通知；
- 代缴时备注栏**必须写申报人姓名**，不写代缴人。

## 五、判断标准

拿不准某个动作该归机器还是归人时，用这条判：

> **这个动作做错了，能不能撤销？**
> 能撤销 → 机器做，人复核。
> 不能撤销，或者涉及钱、章、签字、本人到场 → 人做，机器准备。
