# 职称评审助手（zhicheng-pm）

> 一个把"职称申报"从头跟到尾的 AI 技能包。
> **下层先把一个人打穿**（五道门顺序推进），**上层再把一批人的进度摞成一张表**。
> 版本：**1.2.0**（开源首发版） · 许可：MIT

---

## 一、它解决什么问题

职称申报的坑不在"填表"，在于**一路有很多岔口**：

- 学历是不是理工类，决定你有没有资格——不是理工类，再多年限也白搭；
- 报哪个评委会，决定后面几乎所有参数——学时、论文、窗口、费用、报送地点全跟它走；
- 政策一年一变、一家一个口径——不打开当年原文核，拿旧数据必翻车；
- 材料要凑齐，缺的件还散在不同人手上——本人、单位、第三方、政策窗口；
- 最后几步绕不开人——扫码登录、点提交、缴费、盖章、签字、送纸件、答辩。

这个技能包把上面这些**拆成五道门、写死规矩**，能机器干的先干完，该人上手的提前准备好、一次交接清。

## 二、它长什么样

```
总入口（说一句话，自动分流）
├── 打穿主线   skills/run/            一次推进一步，从资格门走到拿证
├── 第 1 道门   skills/batch-intake/   资格：理工类判定、年限、最早可申报年度
├── 第 2 道门   skills/policy-lock/    定评委会：给候选、讲代价、人拍板
├── 第 3 道门   skills/policy-lock/    锁政策：抄当年学时/论文/窗口/费用
├── 第 4 道门   skills/edu-hours/      继续教育学时缺口与补课排期
│               skills/achievement/    业绩提炼（改写成申报语言）
│               skills/paper/          论文/技术总结方向与提纲
│               skills/unit-material/  单位证明、考核意见、公示
│               skills/assemble/       成册：清单逐项打勾、缺件催补
├── 第 5 道门   skills/track/          申报执行：填写手册、提交、缴费、报送、结果
└── 批量层      references/台账字段.md   N 张进度卡摞成一张台账
```

配套两份参考件：

- `references/执行主线.md` —— 五道门的**进门条件 / 出门交付 / 过不了怎么办 / 谁动手**
- `references/人工把关点.md` —— **机器全包 9 项 + 必须本人 7 项**，以及逐栏填写手册的做法

## 三、怎么用

对话里直接说人话就行，不用记命令：

| 你想干什么 | 这样说 |
|---|---|
| 从头跟一个人 | 「帮张三从头走一遍」「我要报职称，从哪开始」「继续办张三」 |
| 只问一个问题 | 「人工智能专业要多少学时」「这个专业要答辩吗」 |
| 问一批人的进度 | 「这批人现在都到哪一步了」「谁卡超过两周了」 |
| 核继续教育 | 「这批人继续教育核对一遍」 |
| 看材料缺什么 | 「张三的材料清单」「缺什么」 |

三种模式同一个引擎：**打穿模式**一次推进一步；**单点模式**答完就收、不拉你走流程；**批量模式**只汇总，不替单个人做判断。

## 四、安装

把 `zhicheng-pm` 整个目录复制到你的技能目录：

```bash
cp -r zhicheng-pm ~/.workbuddy/skills/     # WorkBuddy
cp -r zhicheng-pm ~/.codex/skills/         # Codex 系
```

技能自带 `SKILL.md`（含 `name` / `description` / 触发词），装好后说「职称评审」即可唤起。

## 五、知识底座

技能包本体是**方法与流程**，可独立运行。政策数据（学时、论文、窗口、费用）**必须回当年官方原文核**，不能套模板：

- **上海市人力资源和社会保障局 · 职称评审通知栏目**
  `https://rsj.sh.gov.cn/tzjjszwpstz_17413/index.html`
- **上海市职称服务系统（申报入口）**
  `www.rsj.sh.gov.cn/zcps/zcpssb/index` —— 首次登录用手机「随申办 APP」注册，**不是账号密码**

建议自建一份知识底座（政策库 / 材料库 / 案例库 / 台账），技能会优先读它；没有也能跑，就是每次都联网现查。

> 本仓库**不包含**任何政策数据、学员材料或案例原件。政策以官方原文为准，案例一律脱敏。

## 六、八条硬红线 + 一条

```
1  政策必须回原文核 —— 旧数据只当线索，给结论前打开当年通知原文
2  评委会不锁定，一切不给做 —— 学时/论文/窗口/费用全看评委会
3  理工类判定是硬门槛 —— 非理工类学历不通，别浪费时间算年限
4  资历截止日分上下半年 —— 上半年 6/30、下半年 12/31
5  学员实名与联系方式不进共享知识库 —— 进度卡与台账放本机
6  不宣称"代办"或与评委会有关系 —— 通知原文明确评委会从未委托任何代办
7  提交/缴费类不可逆动作必须人工确认后执行
8  不替人编学历、编项目、代签、代盖章
9  顺序不可跳 —— 没过资格门不查政策，没定评委会不查学时，材料没齐不提交
```
