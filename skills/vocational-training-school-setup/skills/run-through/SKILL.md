# 手把手主线（A 新办机构 / B 新设职业工种）

## 用途
把用户从「我想办」一路带到「办成了」——**一次只推一门**，每门给出五问卡与下一步动作，不跳门、不跳步。

## 何时用
- 用户说：我要办个培训机构、怎么办、从哪开始、下一步做什么、手把手带我办、我想加一个职业（工种）
- 已给到：**属地（到区县）** ＋ **有没有办学许可证** ＋ **拟培训职业（工种）** ＋ **培训对象是成年人还是中小学生**
- （缺就按 `references/执行主线.md` 第 0 步先问，问到能判路为止）

## 输入
| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 有无《办学许可证》 | 有 / 无 | 用户 | 停下问：这决定走 A 线还是 B 线 |
| 拟培训职业（工种） | 名称（+等级） | 用户 | 停下问：要先判是否在许可范围 |
| 培训对象 | 成年人 / 中小学生 | 用户 | 停下问：答「中小学生」就转校外培训通道 |
| 属地 | 省/市/区县 | 用户 | 停下问：审批按区县执行 |
| 现有推进表 | xlsx（可选） | 用户 | 有就先跑 `scripts/gap_check.py` |

## 步骤
1. **判路**：按 `references/执行主线.md` 第 0 步三问定线（A / B / C）。
2. **禁区检查**：三问里指向「中小学生」→ **停手**，读 `references/channel-contrast.md`，告知另走校外培训通道，本技能不代做。
3. **出主线进度卡**：把该线的**全部门**列出来，标出「已过 / 当前门 / 未开始」。
4. **出当前门五问卡**：进门要什么 · 本门做什么 · 出门交什么 · 谁动手 · 过不了怎么办。
5. **分派动手方**：机器能做的转 `skills/scope-route/`（口径与路线）、`skills/gap-check/`（推进表核对）、`skills/deliverables/`（交付物与催补）；要人做的照 `references/人工把关点.md` 列清单。
6. **用户说「过了」** → 推进到下一门，重出五问卡；直到 A8 / B5 收口。

## 护栏
- **不跳门**：上一门没过不得进下一门；没《办学许可证》＋法人登记，不得提招生收费。
- **一次一门**：不同时铺多门，避免用户迷失。
- **不代办**：盖章、签字、扫码、缴费、现场 —— 只列清单，见 `references/人工把关点.md`。
- **不套数字**：任何门槛数字回属地当期原文核；无原文写「待属地核」。
- **中小学生 = 停**：不得混装两套材料。

## 产出物
- 主线进度卡（全门状态：已过／当前门／未开始）
- 当前门五问卡（进门要什么／本门做什么／出门交什么／谁动手／过不了怎么办）
- 下一步动作清单（机器做什么、人做什么、做完回交什么凭据）
- 交付后转相应子技能；有推进表则并行跑 `skills/gap-check/`

## 交付后请确认
- 通道判断（人社 / 校外培训）请用户确认一次——判错整条重来
- 当前门的「谁动手」里属于人的那几项，需用户落实到具体人
