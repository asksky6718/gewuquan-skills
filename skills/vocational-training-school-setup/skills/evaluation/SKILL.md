# 评价资质（社评组织备案）

## 用途
回答「**能不能发职业技能等级证书**」这条路怎么走：条件够不够、材料要哪些、程序几步、哪几条是硬杠。**不走这条路就不能对外宣称发证。**

## 何时用
- 用户说：社评组织、社会培训评价组织、等级认定、评价机构备案、考核点、发职业技能等级证书
- **须点名**：只有用户明确说出上述触发词才进入，禁止被其他环节顺带拉起
- 前置：**已是依法登记的独立法人**（通常先有办学许可）
（不满足就停下说明缺什么）

## 输入
| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 法人资格 | 营业执照 / 登记证书 | 用户 | 没有就停下：不具备申报主体资格 |
| 拟评价职业（工种） | 名称 + 等级 | 用户 | 停下问；等级须**连续申报** |
| 属地当期遴选公告 | 公告原文 | 省/市级人社部门或职鉴中心 | 没有原文写「待属地核」，只给通用条件 |
| 机构软硬件 | 场地/设备/人员/制度 | 用户 | 逐项对照条件表打勾 |

## 步骤
1. 读 `references/official-process-shanghai.md` 第二节（社评组织遴选的条件、材料、程序）作**提问模板**，逐条向属地确认对应要求。
2. 对照**申报单位条件**逐条打勾（独立法人 / 领域影响力 / 专门机构与专职人员（考评员、质量督导员）/ 质量管控 / 自愿接受监督 / 排他情形）。
3. 列**申报材料六类**（申请表、行业主管部门＋考核点所在区人社推荐函、信用与财务佐证、工作方案、项目实施方案含**两套样卷**、其他），标注每类的填报样张来源。
4. 走**工作程序**：材料提交 → 受理评估 → 机构评估 → 项目评估（通过机构评估后通常 3 个月内完成，逾期视作放弃）→ 公示备案（通常公示 5 个工作日、**有效期 3 年**）→ 公布与证书查询。
5. 列**硬规则**：同一职业遴选家数有限（通常 1 家，部分年份「不超过 3 家」，以当期公告为准）；上一轮未通过者 1 年内不得申报；不得授权或委托他人参与遴选；材料不完整不予受理。

## 护栏
- **办学许可 ≠ 评价资质**：不得把两者混称，也不得暗示「有许可证就能发等级证书」。
- **红线**：备案后发的是**职业技能等级证书**，不是国家职业资格证书；证书须在全国技能人才评价工作网可查。
- 不承诺备案通过、不承诺遴选家数、不承诺等级范围。
- 不代为申报、不代填样卷内容。

## 产出物
- 条件对照表（逐条：满足 / 不满足 / 待属地核）
- 材料清单（六类，含推荐函与样卷的前置责任人）
- 时间表（受理→机构评估→项目评估 3 个月窗口→公示备案）
- 交付后转 `skills/compliance/SKILL.md` 纳入年度台账

## 交付后请确认
- 属地当期遴选公告是否已取到（没有原文则整条结论都要重新核）
- 推荐函由谁去开、样卷由谁出，需用户落到具体人
