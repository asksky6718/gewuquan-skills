# 交付物清单与缺口

## 用途
把「要交什么」变成一张**带证据位置的打勾表**，并把「最常被打回」的点提前标出来。**只做核对与催补，不生成材料。**

## 何时用
- 用户说：要交哪些材料、材料清单、会被退回什么、缺什么件、申报包怎么组
- 前置：**资质路线已定**（只办许可 / 许可＋社评 / 仅社评）
（路线未定就停下，先走 `skills/scope-route/SKILL.md`）

## 输入
| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 资质路线 | 结论 | scope-route | 停下先定路线 |
| 已有材料 | 目录 / 文件清单 / 口头 | 用户 | 先按清单要一遍 |
| 属地材料清单原文 | 办事指南页 | 属地政务网 | 没有原文就按通用清单核，并逐项标「待属地核」 |

## 步骤
1. 打开 `references/checklist-and-gaps.md`，按 **阻断级（★）→ 运行必备（○）→ 预案（△）** 三档逐项打勾。
2. 每项标注**证据形态与位置**（决议文件 / 告知书扫描件 / 合同 / 证照……），没有证据的写「缺」。
3. 对照 `references/checklist-and-gaps.md` 第二节的 12 类常见缺口，逐条自问一遍。
4. 按「缺口处置模板」输出**缺件催补清单**（缺什么 / 找谁要 / 什么时候要 / 依据）。
5. 组包顺序照 `references/application-package-recipe.md`（职业（工种）申报包的六大类与逐份要点）。

## 护栏
- **不生成、不代填**：不代填身份证号、不代写承诺书、不代签、不代盖章。
- 认证/证书表述：分清「职业技能等级证书」与「岗位能力评价证明」，**不得写成国家职业资格**。
- 材料不齐**不催提交**：缺件清单先给，齐了再说下一步。

## 产出物
- 交付物打勾表（含证据索引）＋ 缺件催补清单
- 交付后转 `skills/compliance/SKILL.md`（取得许可后的运行合规）

## 交付后请确认
- 缺件催补清单里每一项的责任人与截止时间，需用户落到具体人
- 属地材料清单原文是否已取到；没取到的项须标「待属地核」
