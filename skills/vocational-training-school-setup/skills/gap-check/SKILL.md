# 推进表机械核对

## 用途
拿到一份推进表，**只做确定性检查**，输出「哪一行、什么问题、应该插在第几步、依据是什么」。**不替用户改表。**
**核心纪律：认得出才核，认不出就拒答**——绝不生成「缺少××」这类假缺口。

## 何时用
- 用户说：检查推进表、进度表、缺什么、顺序对不对
- 已给到：**推进表文件路径（xlsx）**
（没给文件就停下先要，别凭口头描述猜表结构）

## 输入
| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 推进表 | xlsx，含「任务/事项/交付物/责任人/时间节点/状态」这类列（**列名不要求与示例一致**，脚本有别名表） | 用户 | 停下要文件 |
| 属地 | 省/市/区县（可给，仅作报告抬头） | 用户 | 不给也能跑，报告里标「须以属地当期办事指南复核」 |
| 工作表名 | 可选 | 用户 | 不给则扫全部工作表 |

## 步骤
1. 跑脚本：

   ```bash
   python scripts/gap_check.py --xlsx "<推进表.xlsx>" --region <属地> --show-headers --json-out gap.json
   ```

   **退出码**：`0` 无阻断 ｜ `1` 存在阻断 ｜ `2` 文件/依赖问题 ｜ **`3`＝拒答（文件里没有可核对的推进表）**。
2. **看退出码 3**：直接照报告说明「这不是可核对的推进表」，把脚本列出的各表实际表头转给用户，请其指定表或换文件。**不得**改成缺口清单。
3. 读报告，按四级分档：**阻断 / 重要 / 建议 / 提示**。阻断级只保留「不做就不能合法招生」的项。
4. 若报告标「**空模板**」：说明该表尚未填时间/状态/责任人，**不要**报「缺少××任务」；改提示用户先填表。
5. 对每条阻断/重要，照 `references/checklist-and-gaps.md` 的「缺口处置模板」补齐：**建议插入位置 ＋ 交付物 ＋ 可判验收标准 ＋ 时间节点 ＋ 依据**。
6. 输出修订建议（不直接改用户的表）。

## 脚本认什么（v2.1 行为，认不出即拒答）
- **表头别名表**：模块/阶段/分类/母项目 → 重点任务；事项/子项目/细项 → 具体事项；关键交付物 → 交付物；责任人/主办人 → 负责人；协助/相关协同方 → 协同方；完成状态 → 当前状态；到位时间/截止时间/开始时间 → 时间节点……
- **两行复合表头**：自动把「第一年」＋「第一季度」这类上下两行拼起来认；数据从表头**下一行**起读（单行表头 +1／两行复合 +2）——**不会吃掉第一行数据**。
- **矩阵表**：识别「按季度横向铺开」的计划矩阵（季度列 ≥3 个），按「分类/子项目/责任人/到位时间」核，**不对季度格逐格判日期**。
- **像推进表的最低要求**：命中 ≥3 列，且至少含「负责人／当前状态／时间节点／交付物／验收标准」之一——只有「模块/事项/备注」的说明表会被判为**非推进表**并跳过。
- **空模板识别**：识别到表但时间/状态/责任人全空 → 判为**空模板**，不报缺失。
- **日期粒度**：`2026-11`、`2026年11月` 这类**只到月**的节点算合法（顺序核对按月初／月末折算）；`2026-15` 这类月/日越界才算非法。「待定 / 视审批进度 / 长期」等**软表述**降级为提示，不当缺陷。
- **缺列只报一次**：全表没有「验收标准」这类列时只出一条，**不逐行刷屏**；列存在才逐行查空值。
- **状态白名单宽**：`未开始 / 待启动 / 进行中 / 已完成 / 暂停 / 不适用` 等 24 个常见状态都算正常，只抓「状态与备注自相矛盾」（如标「已完成」但备注含「待核」）。

## 护栏
- **不改用户的表**：脚本只读，报告只写 `--json-out` 指定的 JSON。
- **不自动安装依赖**：缺 `openpyxl` 时报错退出，只在提示里说「请在虚拟环境或已装 openpyxl 的解释器中运行」。
- **不做主观评价**：脚本只输出事实（第几行、什么现象），分级结论由本环节给出并说明依据。
- **拒答优先**：认不出表时**宁可拒答，不可硬报缺口**。

## 产出物
- 推进表机械核对报告（四级缺口表）＋ JSON（可选）
- 缺口补充清单（交付物 / 可判验收标准 / 时间节点 / 依据）
- 交给用户修订；补齐后转 `skills/deliverables/` 逐项打勾

## 交付后请确认
- 阻断级缺口请用户先认（这些是「不做就不能合法招生」的项）
- 需要插入的任务由谁负责、什么时候完成，需用户落到责任人
- 若本次是**拒答**，请用户确认要核哪张表（或补一张推进表再核）
