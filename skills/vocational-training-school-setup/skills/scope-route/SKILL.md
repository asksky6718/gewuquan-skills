# 口径与路线

## 用途
把一个模糊的「我要办个培训学校」，收敛成一张**属地口径卡**（审批机关 / 依据文号 / 材料清单从哪取）＋一条**资质路线**（要不要走评价资质）。**只到"路线定下来"为止，不往下做材料。**

## 何时用
- 用户说：向哪个部门申请、审批机关是谁、依据什么文件、我要办培训学校、要不要申请社评组织
- 已给到：**属地（省/市/区县）** ＋ **机构属性（营利 / 非营利）** ＋ **拟培训职业（工种）**
（缺任意一项就停下先问，不要替用户假设）

## 输入
| 项 | 形态 | 从哪来 | 缺了怎么办 |
|---|---|---|---|
| 属地 | 省/市/区县 | 用户 | 停下问：审批按区县执行，缺了没法查 |
| 机构属性 | 营利 / 非营利 | 用户 | 停下问：名称核准与登记机关完全不同 |
| 拟培训职业（工种） | 名称 | 用户 | 停下问：要先确认是否在许可范围 |
| 是否要发职业技能等级证书 | 是 / 否 / 不确定 | 用户 | 不确定就按「先办学许可、预留评价路线」处理 |

## 步骤
1. 确认**审批机关**：培训类审批按区/县级人社部门执行（省级定标准、市级指导）。产出：审批机关全称。
2. 取**属地当期办事指南原文**：一网通办 / 政务服务网的「办事指南」页。产出：链接 + 取数日期。
3. 记录**上位依据文号**（省/市级管理办法等）。产出：文号。
4. 判断**拟培训职业是否在许可范围**（技能类、非准入类）。产出：在 / 不在 / 待属地核。
5. 定**资质路线**三选一，并写清理由：
   - 只办办学许可（自己开班培训，不发等级证书）
   - 办学许可 ＋ 社评组织备案（要对外开展职业技能等级认定）
   - 仅社评组织备案（已是独立法人，且有评价能力，不办培训）
6. 输出**属地口径卡**并交用户确认。

## 护栏
- **不给任何数字门槛**（面积、资金、时限、学时……）；`references/` 里的数字一律标注「仅作提问清单，须回属地当期文件核」。
- **不跨地区套用**：湖北的数字不能写进上海材料，A 县的数字不能写进 B 县材料。无原文就写「待属地核」。
- **不承诺**审批结果、办结时限、补贴金额。

## 产出物
- 属地口径卡（审批机关 / 依据文号 / 材料来源链接 / 取数日期）＋ 资质路线结论
- 交给用户拍板；路定了转 `skills/gap-check/`（如已有推进表）或 `skills/deliverables/`

## 交付后请确认
- 属地口径卡里的审批机关与依据文号，请用户核对是否与手上材料一致
- 资质路线（要不要走评价资质）需用户拍板，定了再往下
