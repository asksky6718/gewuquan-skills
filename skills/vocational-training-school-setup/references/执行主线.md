# 执行主线（手把手 · 两条路）

> 用法：**先判走哪条路，再一门一门过**。一次只推一门，过不了就停在那门，不许跳。
> 每门固定五问：**进门要什么 → 本门做什么 → 出门交什么 → 谁动手 → 过不了怎么办**。
> 全文所有数字（面积／资金／学时／时限／费用）**只是提问清单**，落地前必须取属地当期办事指南原文。

---

## 第 0 步 · 判路（三问答完就定）

| # | 问 | 答「是」→ | 答「否」→ |
|---|---|---|---|
| 1 | 手上已有《办学许可证》和法人登记吗？ | 走 **主线 B**（新设职业/工种） | 走 **主线 A**（从零办机构） |
| 2 | 需不需要对外发**职业技能等级证书**？ | A 或 B 走完，再进**评价资质**（须点名） | 不进出口 |
| 3 | 培训对象是**中小学生**吗？ | **停**——这是校外培训，另一套审批体系，见 `references/channel-contrast.md` | 继续 |

> **第 3 问答「是」就必须停**：面向中小学生的校外培训归**教育／体育**部门，与「民办职业培训学校（人社）」是**两条完全不同的通道**，材料与机关都不同，套错等于白做。

---

# 主线 A · 新办一家培训机构（八门）

## A1 · 立项与路线

| 项 | 内容 |
|---|---|
| **进门要什么** | 谁办（举办者主体与性质）· 办什么（拟培训职业/工种）· 在哪（属地到**区县**）· 投多少（资金来源）· 谁负责 |
| **本门做什么** | ① 定**审批机关**（区/县级人社部门）② 取**属地当期办事指南原文** ③ 记**上位依据文号**（省市级管理办法）④ 判拟培训职业**是否在许可范围**（技能类、非准入类）⑤ 定**资质路线**三选一 |
| **出门交什么** | 《属地口径卡》（审批机关／依据文号／材料来源链接／取数日期）＋ 资质路线结论 |
| **谁动手** | **机器**出卡与结论（`skills/scope-route/`）；**举办者本人拍板**路线与出资 |
| **过不了怎么办** | 属地查不到当期指南 → **挂起**，先取原文；**禁止**拿别地数字顶（红线第 9 条） |

## A2 · 名称核准

| 项 | 内容 |
|---|---|
| **进门要什么** | A1 的路线卡；机构属性（**营利 / 非营利**） |
| **本门做什么** | 营利 → 名称自主申报，取**名称自主申报告知书**（市场监管）；非营利 → **名称预核准文件**（民政） |
| **出门交什么** | 名称核准件（告知书或预核准文件） |
| **谁动手** | **本人**做实名申报（要账号、要实名认证）；机器核名称与业务范围、办学层次是否匹配 |
| **过不了怎么办** | 名称与业务不匹配 → 改名重报；**注意有效期**，别拖到过期 |

## A3 · 筹设（可选门）

| 项 | 内容 |
|---|---|
| **进门要什么** | 名称核准件 + 资产来源与有效证明（载明产权）+ 申办报告 |
| **本门做什么** | 提交筹设申请；告知承诺制地区并交承诺书 |
| **出门交什么** | 筹设批准文件 |
| **谁动手** | 本人提交；机器盯两件事 |
| **过不了怎么办** | — |
| **⚠️ 本门红线** | **筹设期内不得以任何名义招生、收费、开展教学**；筹设批准通常**3 年内**必须提出正式设立申请，逾期**自然废止** |

## A4 · 正式设立申请（材料门）

| 项 | 内容 |
|---|---|
| **进门要什么** | A3 结果（或免筹设）＋ 全部前置件 |
| **本门做什么** | 备齐属地要求的全套材料。通用十一项：**①申办报告＋申请审批表 ②举办者主体信息 ③名称核准件 ④办学章程及管理制度（成册）⑤决策机构名单（理/董事会、监事会）⑥教学管理人员资格 ⑦校长·教师·财务人员资格证明＋劳动合同 ⑧注册资金验资报告＋固定资产证明 ⑨场所产权证明或租赁合同 ⑩设施设备清单及权属证明 ⑪建筑与消防安全达标材料** |
| **出门交什么** | 完整申报包（逐项给证据位置）|
| **谁动手** | 机器出**打勾表＋缺件催补清单**（`skills/deliverables/`）；**人**取证、签合同、盖章 |
| **过不了怎么办** | 缺件 → 按催补清单补，**补齐前不提报** |
| **⚠️ 本门最常被打回** | 场地（面积/楼层/土地性质/产权不清）· 消防（缺**二次消防**验收或备案）· 验资报告过期 · 校长教师财会**不持证或与拟培训职业不匹配** · 制度未成册 |

## A5 · 审查与许可

| 项 | 内容 |
|---|---|
| **进门要什么** | A4 完整申报包 |
| **本门做什么** | 受理 → 材料审查（可含**专家评审、现场考察**）→ **公示**（特别程序）→ 发《民办学校办学许可证》 |
| **出门交什么** | **《办学许可证》** |
| **谁动手** | 本人提交与到场；机器排时间表、盯回补窗口 |
| **过不了怎么办** | 被告知补正 → **按告知期限回补**，逾期视为放弃 |
| **⚠️ 告知承诺制** | 发证后通常 **3 个月内**复核；不符 → 限期整改；逾期或整改不到位 → **吊销** |

## A6 · 法人登记

| 项 | 内容 |
|---|---|
| **进门要什么** | 《办学许可证》 |
| **本门做什么** | 营利 → 市场监管办**营业执照**；非营利 → 民政办**民办非企业单位登记**（可能需业务主管单位前置审查） |
| **出门交什么** | 营业执照 或 民非登记证书 |
| **谁动手** | 本人办理；机器核两证信息一致 |
| **⚠️ 红线** | **办学许可 ＋ 法人登记两证齐备，方可招生与教学**。只拿执照 ≠ 有资质办学 |

## A7 · 开办配套（一次做全）

| 项 | 内容 |
|---|---|
| **本门做什么** | 视频监控 · 消防设施 · 场地标识 · 师资到位 · 教材与教学计划/大纲 · **收费项目与标准公示** · **培训协议模板（含退费条款）** · **学员实名制档案与培训台账** · 招生简章与广告合规审查 · 保险与安全预案 |
| **出门交什么** | 上述十项的落地物与留痕 |
| **谁动手** | 机器出模板与检查表；**人**落实场地、公示、签协议 |
| **过不了怎么办** | 逐项对照，缺哪补哪 |

## A8 · 依法运行

| 项 | 内容 |
|---|---|
| **本门做什么** | **年检**（多为每年组织一次、**一季度末前**完成）· 变更报批/备案（举办者/法人/校长/地址/名称/职业/层次、设分校、分立合并）· 终止预案（方案＋清算＋学员安置＋注销＋公示）· 广告·收费·用工·资金审计 |
| **出门交什么** | 合规运行台账（事项／频次／责任人／依据／证据位置） |
| **谁动手** | 机器排期与台账（`skills/compliance/`）；人按期报送 |
| **过不了怎么办** | 不接受或不合格 → 限期整改 → 逾期**取消办学资格** |

# 主线 B · 已有机构新设职业（工种）（五门）

## B1 · 主体与许可范围

| 项 | 内容 |
|---|---|
| **进门要什么** | 《办学许可证》＋法人登记（两证齐备）；拟新增职业（工种）名称 |
| **本门做什么** | ① 核**许可范围**：新职业是否属人社部技能人员新职业／《职业分类大典》三至六大类中有明显技能特征者 ② 核**办学地址与场地**是否覆盖新增职业的实训要求 |
| **出门交什么** | 《主体与范围核对单》（在范围 / 不在范围 / 待属地核） |
| **谁动手** | 机器核；**人**确认场地与设备实况 |
| **过不了怎么办** | 不在许可范围 → 先申请调整办学范围或换职业 |

## B2 · 定职业等级 + 对门槛表

| 项 | 内容 |
|---|---|
| **进门要什么** | 拟申报的**职业（工种）＋等级**（如五级/四级/三级） |
| **本门做什么** | 取属地《培训机构职业设置条件（试行）》作**门槛表**，逐条对照：班规模 · 师资人数（理论/实训）· 从教资格 · 从业经历 · 理论场地 · 实操场地 · 设备（逐项最低配置）· 软件 · 教学资料 · 环境（安全照明消防通风） |
| **出门交什么** | 门槛表逐条对照结果（达标 / 不达标 → 补的排期 / 待属地核） |
| **谁动手** | 机器出对照表与访谈提纲；**人**拿属地下发的当期标准来对 |
| **过不了怎么办** | 不达标项先补再报；**不得照抄别地示例数字** |
| **⚠️ 易错** | 申请表**按等级分表**——报三级就交三张，不是一张表填三行；等级通常须**连续申报**（如 5-4-3） |

## B3 · 组申报包（六大类）

| 项 | 内容 |
|---|---|
| **进门要什么** | B2 对照结果 + 已有材料清单 |
| **本门做什么** | 按六大类装包：**①申请报告（1 份）②职业（工种）申请表（每等级一张）③教学文件（每等级一套：设置标准／教学计划／大纲与教材）④教师材料（每人一套七件）⑤场地证明（产证／租赁合同／无偿使用三选）⑥其余按属地要求** |
| **出门交什么** | 完整申报包 + 打勾表（含证据位置） |
| **谁动手** | 机器出配方与打勾表（`references/application-package-recipe.md`）；**人**取证、盖章、签合同 |
| **过不了怎么办** | 缺件 → 催补清单，补齐前不提报 |
| **⚠️ 本门最常被打回** | 三个等级的**课程名三处不一致** · 设备清单**未逐条标适用等级** · 教师身份证/合同/简历**三处信息不一致** · 场地合同期限**覆盖不了办学周期** · 教材**非正版公开出版物** |

## B4 · 报送与审查

| 项 | 内容 |
|---|---|
| **进门要什么** | B3 完整申报包 |
| **本门做什么** | 报送（线上系统或窗口）→ 受理 → 材料审查 →（可有**现场核查**）→ 审批意见 |
| **出门交什么** | 批复结果（获准增设的书面结果） |
| **谁动手** | **本人提交**（实名/扫码）；机器排时间表、盯回补窗口 |
| **过不了怎么办** | 不予受理/退回 → 按告知补正，**在告知期限内回补** |

## B5 · 获批纳管

| 项 | 内容 |
|---|---|
| **进门要什么** | B4 批复 |
| **本门做什么** | ① 更新**办学许可载明的职业（工种）**信息 ② 收费项目与标准**重新公示** ③ 新增职业的**教材、课表、教师台账**入册 ④ 纳入**年检**范围 |
| **出门交什么** | 更新后的台账与公示 |
| **谁动手** | 机器出台账；人公示与入册 |
| **过不了怎么办** | 未更新公示即招生 → 属违规，先公示后招生 |

---

## 两条主线的共通纪律

1. **顺序不可跳**：没拿到《办学许可证》＋法人登记，**不得招生、收费、开课**（A6 红线）；B 线不得在批复前对外宣称已开设该职业。
2. **一次只推一门**：过不了就停在那门，把「过不了怎么办」执行完再往下。
3. **凡是盖章、签字、扫码、缴费、到现场的** —— 机器不代办，见 `references/人工把关点.md`。
4. **每一门的结论后跟依据**（文件名／文号／网址）；没取到原文的写「**待属地核**」。
5. **判路第 3 问答「是」（中小学生）** → 立刻停，走 `references/channel-contrast.md`。
