# 人工把关点（机器不代办清单）

> 判据一句话：**凡是要盖章、要签字、要扫码、要花钱、要到现场的，机器不代办。**
> 机器把准备做到位（清单、模板、口径、时间表），最后那一下由人做，并**把凭据回交机器**。

## 一、必须本人做的（A / B 两条主线都适用）

| # | 把关点 | 在哪一门 | 为什么必须本人 | 做完回交什么 |
|---|---|---|---|---|
| 1 | **取属地当期办事指南原文** | A1 / B2 | 需登录政务网，且各地当期口径不同 | 链接 ＋ 取数日期 ＋ 关键要素截图 |
| 2 | **名称自主申报 / 名称预核准** | A2 | 需**实名认证**，主体身份绑人 | 告知书或预核准件 |
| 3 | **场所与消防核实** | A4 / B1 | 必须**到现场**看面积/楼层/土地性质/二次消防 | 现场结论 ＋ 验收或备案文件 |
| 4 | **验资与固定资产证明** | A4 | 需银行与评估出件 | 验资报告 ＋ 资产证明 |
| 5 | **教师劳动合同与证书原件** | A4 / B3 | 需**本人签字**、原件核验 | 合同原件 ＋ 证书扫描件 |
| 6 | **章程与制度签署、决策机构名单** | A4 | 需决策机构会议与签署 | 签署件 |
| 7 | **单位盖章** | A4 / B3 / B4 | 公章不可代盖 | 盖章件 |
| 8 | **提交申报** | A5 / B4 | 多为**实名或扫码**提交 | 受理号 |
| 9 | **缴费**（如涉及，如评审/工本费） | A5 / B4 | 涉**钱**，逐次放行 | 缴费凭证 |
| 10 | **现场考察 / 答辩到场** | A5 / B4 | 需人到场应答 | 考察或答辩结论 |
| 11 | **领取证照 / 批复** | A5 / A6 / B4 | 需签收或实名领取 | 证照或批复扫描件 |

## 二、机器全包的（人不必看过程，只看结果）

| 项 | 产出 |
|---|---|
| 属地口径对照 | 属地口径卡（审批机关／依据文号／材料来源／取数日期） |
| 推进表机械核对 | 缺口四级清单（缺任务／日期非法／状态越权／空值／顺序倒置） |
| 交付物打勾 | 打勾表（含每项证据形态与位置） |
| 缺件催补 | 催补清单（缺什么／找谁要／什么时候要／依据） |
| 申报包配方 | 六大类怎么装、每份看什么、逐项自检 |
| 材料模板 | 协议模板、台账表、公示文本（**给模板，不代填真实信息**） |
| 进度与时限 | 时间表（含回补窗口、年检到期提醒） |
| 评价资质对照 | 条件打勾表、材料六类、程序时间表 |

## 三、机器明确不做的（红线）

- ❌ **不代填身份证号、不代写承诺书、不代签、不代盖**
- ❌ **不代办提交、不代转账缴费**
- ❌ **不承诺**审批通过、办结时限、补贴金额、评审结果
- ❌ **不把**「办学许可」当「社评组织备案」，也不暗示「有许可证就能发等级证书」
- ❌ **不生成**虚假材料、不套用其他地区模板或数字

## 四、回交凭据的最小要求

人做完第 1–11 项后，回交机器只需三样：**① 凭据（件名或编号）② 日期 ③ 谁做的**。
机器据此把推进表对应行的「当前状态」改为「已完成」并登记证据位置。
