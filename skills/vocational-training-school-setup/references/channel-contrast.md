# 两条通道别混：人社 · 职业培训 ≠ 教育／体育 · 校外培训

> 这份文件只干一件事：**进门先判对通道**。判错通道，材料、机关、表格全不对，等于白做一遍。

## 一、三问定通道

| # | 问 | 答 | 归口 |
|---|---|---|---|
| 1 | **培训对象是谁？** | 成年人（在职/转岗/再就业） | 大概率 → **人社 · 职业技能培训** |
| 1 | | **中小学生（含学龄前）** | → **教育／体育等主管部门 · 校外培训** |
| 2 | **培训什么？** | 国家职业技能标准里的**职业（工种）**（如人工智能训练师、电工、康养照护员） | → **人社** |
| 2 | | **体育／艺术／科技类兴趣特长**（篮球、羽毛球、乒乓球、体适能、跆拳道、美术、编程启蒙） | → **教育／体育／文旅／科技等主管部门** |
| 3 | **谁管？** | 区/县级**人社部门** | → 人社通道 |
| 3 | | **教育行政部门**（学科类）或**非学科类主管部门**（体育、文旅、科技等） | → 校外培训通道 |

**三问只要有一问指向「中小学生」或「兴趣特长」，就整条走校外培训通道。**

## 二、两条通道对照

| 项 | 民办职业培训学校（**人社**） | 校外培训机构（**教育／体育**） |
|---|---|---|
| 主要人群 | 成年人为主 | **中小学生**（含学龄前） |
| 审批机关 | 区/县级**人社部门** | **教育行政部门**（学科类）／**体育、文旅、科技等主管部门**（非学科类），按属地设置标准 |
| 上位依据 | 民办职业培训学校管理办法（省/市级）· 成人培训机构设立与管理实施办法 | 属地**校外培训机构设置标准**（含消防、场地、师资专项要求） |
| 主要证件 | 《民办学校办学许可证》＋法人登记 | 办学许可／审核意见书等（按属地口径） |
| 典型内容 | 人工智能训练师、电工、康养照护、育婴、电子商务师等**职业技能** | 篮球、羽毛球、乒乓球、体适能、跆拳道等**体育类**；美术、书法等艺术类 |
| 能否发等级证书 | 需**另办社评组织备案**才能对外发职业技能等级证书 | **不得**发职业技能等级证书 |
| 常见退件原因 | 拿体育类校外培训材料报人社 | 拿成年人技能培训材料报教育／体育 |

## 三、本技能的边界（写死）

- ✅ 本技能覆盖：**人社通道**（民办职业培训学校办学许可 ＋ 已有机构新设职业/工种 ＋ 社评组织备案）。
- 🛑 出现以下任一信号 → **停手**，明确告诉用户「这是校外培训通道，不归本技能」：培训对象为**中小学生**、培训内容为**体育/艺术/科技兴趣特长**、材料里出现**「校外培训」「中小学生」「培训项目目录（体育类）」**。
- 🛑 本技能**不代做**校外培训通道的申报包，也不把两套材料**混装**。
- ⚠️ 两套通道**门槛数字一律不互相套用**（面积、师资、消防要求各不相同）。

## 四、落地判据（写进每份产出）

产出开头必须写清一句：**本件适用通道＝人社·职业技能培训**（或）**本件不适用，应走校外培训通道**。
没写这一句的产出，视为未完成。
