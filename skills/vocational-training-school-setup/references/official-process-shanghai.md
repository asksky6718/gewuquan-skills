# 上海口径 · 民办职业培训学校办学许可 与 社会培训评价组织遴选

> 来源：上海市一网通办（zwdt.sh.gov.cn）、上海市人社局（rsj.sh.gov.cn）、上海市教委（edu.sh.gov.cn）、上海市人民政府。取数日期 2026-10-08。

## 一、办学许可（培训资质）

**事项**：民办职业培训学校办学许可（设区的市级权限）／筹设审批（设区的市级权限）
**权限划分**：**区人力资源和社会保障部门**负责民办职业培训学校办学许可（新设）的**受理、审核、发证**
**范围**：市行政区域内国家机构以外的法人或自然人，利用非国家财政性经费，面向社会举办、专门从事国家职业资格、专项职业能力、技能等级评价及其他技能类培训项目
**办理形式**：窗口办理、网上办理、快递申请；**全程网办**（网上咨询/收件/预审/受理/办理/结果反馈）

**准予许可的法定条件（4 条）**：①有组织机构和章程；②有合格的教师和管理人员；③有与所实施职业教育相适应、符合规定标准和安全要求的教学及实习实训场所、设施、设备以及课程体系、教育教学资源等；④有必备的办学资金和与办学规模相适应的稳定经费来源。

**办理时限（公示值）**：收件 0 → 受理 5 → 审查 8 → 决定 8 → 颁证与送达 10（工作日）；特别程序：**专家评审、向社会公示**；审批不收费。

**筹设审批要点**：材料含联合办学协议、资产来源与资金数额及有效证明（捐赠另附捐赠协议）、告知承诺书（一式 2 份、双方签章、须在经营场所公开）、举办者资质证明、申办报告（含申请表）、名称核准通知书（民非名称核准或企业名称预先核准）。形式审查**当场作出决定**；**批准筹设之日起 3 年内**未提出正式设立申请的，原筹设批准文件**自然废止**；**筹设期内不得以任何名义开展招生与培训教学活动**。准予筹设后 **2 个月内**检查承诺属实性；不符→限期整改（最长 1 个月）；仍不符→撤销筹设批准。

**设立流程（《上海市成人培训机构设立与管理实施办法》第六条）**：①先办名称预保留/核准（营利→市场监管；非营利→民政）；②向许可机关提设立申请，许可机关依法审核并可组织评估论证，批准的发**办学许可证**，不批准的说明理由，人社部门将批准信息抄告同级教育部门（非营利还需办业务主管单位前置审查）；③取得办学许可证后到登记机关办**法人登记**；**取得办学许可并完成法人登记后方可开展招生及教学活动**。

**许可范围限制**：面向成年人以职业技能为主的职业资格培训、职业技能培训机构，由区人社部门许可；许可培训项目范围为**人社部发布的技能人员新职业**，或《职业分类大典》第三至第六大类中具有明显技能特征（除行政执法类）的职业工种。

## 二、社会培训评价组织（社评组织）遴选备案（评价资质）

**定义**：经人社部门备案、面向社会提供职业技能等级认定、颁发职业技能等级证书的评价机构。受市人社局委托，市职鉴中心分批公开征集、择优遴选。

**申报单位条件（同时满足）**
1. 本市依法登记的独立法人（企业、社会团体、院校、民非等），以人才培养服务为主要工作职责，财务与管理制度规范，**社会信用良好、无违法违规失信记录**；院校须有相关培训评价经历且规模较大。
2. 在拟评价职业领域有广泛影响力，在所申报职业（工种）方面有较丰富考核评价经验与基础条件。
3. 有**专门负责等级认定工作的机构**、相适应的**专职工作人员、专家团队、考评人员、内部质量督导人员**，以及场地、设备设施（**含视频监控设备**），能提供稳定经费保障。
4. 有完善的**质量管控措施**，社会效益优先，**不以营利为最终目的**。
5. 自愿接受各级人社部门监督。
6. 另有：**政府及其所属部门（事业单位、未与政府部门脱钩的社会团体）不予申报**；**上一轮遴选评估未通过的，1 年内不得申报**。

**申报材料（6 类）**：①征集遴选申请表；②**行业主管部门（或上级主管部门）推荐函 ＋ 考核点所在区人社部门推荐函**；③信用佐证（信用报告、近两年财务审计报告等）＋法人登记证书或营业执照复印件；④**职业技能等级认定工作方案**（含承诺书、廉洁责任书等）；⑤**职业技能等级认定项目实施方案**（含各等级评价方案及**两套样卷/样题**等）；⑥其他材料。各材料有填报样张（附件 1-2 至 1-17 类）。

**工作程序**：材料提交（线上系统录入/上传）→ 受理评估（材料核验、专家论证、现场考察）→ **机构评估**（专家论证、现场答辩、实地考察）→ **项目评估**（通过机构评估后 **3 个月内**完成，逾期视作放弃）→ **公示备案**（公示 5 个工作日；无异议后出具备案回执，含备案编号与**有效期 3 年**，并向中国就业培训技术指导中心报备）→ 信息公布（市人社局官网「上海职业技能鉴定」栏目、技能人才评价工作网 www.osta.org.cn 可查）。

**其他硬规则**：原则上**每个职业（同一职业编码）遴选一家**（部分年份表述为「一般不超过 3 家」，以当期公告为准）；申报项目应按 **5、4、3 级或 2、1 级连续等级**申报；**同一单位一年内不得多次参与同一职业（工种）**遴选；**不可授权或委托其他组织、个人参与遴选**；材料不完整不予受理；虚假承诺/资料经核实取消申报资格，已备案的**终止备案**。

**申报入口**：上海市人力资源和社会保障自助经办系统 `https://zzjb.rsj.sh.gov.cn/zzjbd1/` → 「劳动就业」→「技能鉴定」→「新增备案机构申报」。

**职业（工种）纳入征集目录的条件**：属技能类职业（工种）且已颁布国家职业标准（**准入类职业资格不纳入**）；聚焦国家重大战略与本市「3+6」重点产业、急需紧缺、民生保障及新经济新业态；社会通用性强、专业性强；未来 3 年有较大评价需求。
