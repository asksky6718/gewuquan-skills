# 交付物检查表 与 常见缺口

| # | 交付物 | 阻断级 | 证据形态 |

| 1 | 办学决议/立项备案（含出资与责任人） | ★ | 决议文件或备案回执 |
| 2 | 名称核准文件（名称自主申报告知书 / 民非名称预核准） | ★ | 告知书扫描件 |

| 8 | 场所产权证明或租赁合同（含土地性质、面积、楼层） | ★ | 合同/权证 |

## 二、常见缺口（机械核对脚本会自动命中这几类）

1. **资质链缺失**：推进表里有装修、招生、开课，但没有「办学许可」「法人登记」任务 —— 顺序风险最高的缺口。
2. **立项备案缺失**：招生/宣传任务备注写着「依赖立项备案」，但全表没有立项备案任务行。
3. **场地与消防前置缺失**：没有「场地合规确认」「消防（二次消防）验收」独立任务，只在装修里一笔带过。
4. **人员资格缺失**：有人事编制，但没有「校长/教师/财会资格确认与劳动合同」任务。
5. **资金与资产缺失**：没有验资、固定资产证明事项。
6. **运行合规缺失**：没有收费公示、培训协议、实名制台账、年检任务。
7. **评价资质缺失**：若目标是发职业技能等级证书，必须有社评组织/考核点相关任务，否则对外不得宣称发证。
8. **日期非法或格式不一**：如 `2026-15`、混用「—」「-」「至」、区间跨越不合理。
9. **状态越权**：「已完成」用于尚需外部确认（如主体全称待核对）的事项；「已确认」但缺佐证。
10. **责任人单点**：全部任务同一责任人，无复核人；外部协同事项无对方确认人。
11. **口径未核**：出现「补贴」「保就业」「包推荐」等表述却无当期文件依据。
12. **验收标准不可判**：写「形成效果」这类无法判定的验收标准，改为可判（如「具备授课条件：投影/网络/账号全部可用并留检查表」）。

## 三、缺口处置模板

```
【阻断级】缺「××」任务 → 建议插入位置：第 X 阶段（在「××」之前）
  交付物：…
  验收标准（可判）：…
  时间节点：YYYY-MM-DD—YYYY-MM-DD
  依据：<文件名/文号/网址>
```

## 四、口径纪律（写指导文件时必须守）

- 补贴、减免、就业类表述：只写「以当地当期文件为准」，**不给数字、不给承诺**。
- 认证/证书表述：分清「职业技能等级证书」与「岗位能力评价证明」，不得写成国家职业资格。
- 外采平台、硬件、认证通道：按实际来源标注，不称自有。
- 对外材料不出现未签约的第三方机构具名。
