# 职业（工种）申报包配方

> 用途：办理**民办职业培训学校「新增职业（工种）」**这类事项时，一份**完整的申报包**长什么样。
> 来源：从一套实际提交的上海申报材料（2025-05 报送，见 `case-shanghai-ai-trainer.md`）＋ `official-process-shanghai.md` 提炼。
> **本文件只给"装什么、每份看什么"，不给通过承诺；属地材料清单与页数要求一律以当地当期办事指南为准。**

## 一、六大类（装包顺序）

| # | 大类 | 份数规律 | 核心作用 |
|---|---|---|---|
| 1 | **申请报告** | 1 份 | 讲清「谁办、办什么、为什么办、办到什么规模」 |
| 2 | **职业（工种）申请表** | **每个等级各一张** | 审批机关据以作出决定的正式表格 |
| 3 | **教学文件** | 每等级一套 | 证明「你真的会教」：设置标准、教学计划、大纲、教材 |
| 4 | **教师材料** | **每位教师一套** | 证明「有人能教」：资格、经历、劳动关系 |
| 5 | **场地证明** | 1 套 | 证明「有地方教」：产权、租赁或无偿使用 |
| 6 | 其余按属地要求 | — | 章程制度、验资与固定资产、消防、设施设备清单等（见 `checklist-and-gaps.md`） |

> **易错点**：第 2 类**按等级分表**——报三个等级就交三张表，不是一张表填三行。

## 二、逐类要点

### 1. 申请报告
抬头是**属地区人社局**。正文通常按这七栏写：

1. **办学宗旨**：培养什么人才、服务什么产业
2. **培养目标**：主导方向＋兼顾的在职/岗前/再就业培训
3. **办学规模**：首年计划培训人数
4. **举办者概况**：机构名称、办学地址与邮编、联系电话、法定代表人、校长、举办者（公司或个人）
5. **办学形式**：面授 / 线上 / 混合
6. **拟增设职业（工种）及培训层次**：逐级列出（如 X 五级、四级、三级）
7. **招生对象**：面向哪几类人

> **坑**：报告里常引产业政策与市场数据。**引用市场数据须标注原始出处**；没有出处的增长数字不要放进对外材料。

### 2. 职业（工种）申请表
封面四项：申请单位全称（加盖公章）、职业（工种）、培训等级、申请日期；另有**审批编号规则**（示例：8 位数，前 2 位审批年份、3–4 位月、5–6 位日、7–8 位年度序号）。表体四块：

| 块 | 看什么 |
|---|---|
| 培训单位基本情况 | 地址、邮政编码、联系电话 |
| 培训场地及设施设备 | 教室间数、实习场地面积、出租单位与合同期限、**设备清单要逐条标适用等级** |
| 师资情况 | 持教师资格证人数、兼职人数、持聘用合同的兼职人数；理论课/实习课教师逐人一行（姓名、职称、教师资格任教学科、联系电话、编制所在单位及职务） |
| 承诺与审批意见 | 申请单位承诺＋印章；人社部门审批意见＋印章（申请人只填到承诺栏） |

> **填表说明**通常写明「一式三份（一份留存、两份报批）」「每个专业每个等级分别填报一张」「可加附页」。

### 3. 教学文件（三件）
1. **职业设置标准**：属地下发的《培训机构职业设置条件（试行）》—— **这是"门槛表"**，逐条对照（见第三节）。
2. **教学计划**：课程基本信息（课程名称 / 培训等级 / 总课时（理论＋实操＋考核）/ 适用对象 / 培训目标）＋ **课程模块与课时分配表**。
3. **教学大纲与拟使用教材**：每个模块写「教学目标 / 教学内容（分课时）/ 实训项目」；末尾列考核方案与教材（主教材＋辅助材料），教材须是**正版公开出版物**或官方标准。

### 4. 教师材料（每人一套七件）

| 件号 | 材料 | 看什么 |
|---|---|---|
| 4-1 | 培训教师简历 | 学历与所学专业、职业资格/聘任证、工作经历与成果、承担教学职业/等级 |
| 4-2 | 个人承诺书 | 本人签字 |
| 4-3 | 学历（学位）证书 | 与所教职业方向是否匹配 |
| 4-4 | 教师资格证 / 教师上岗证 | **从教资格的硬门槛** |
| 4-5 | 职业资格 / 技术等级 / 聘任证 | 证明专业能力（可多份） |
| 4-6 | 身份证 | 与合同、简历一致 |
| 4-7 | 聘用（兼职）合同 | 期限、岗位、报酬、双签 |

**兼职合同要点**：聘用方（举办者）、受聘方、受聘岗位与工作地点、**固定期限（常见 2 年）**、工作时间不固定、**按课时计酬**、发薪日、保密条款、变更/解除/终止情形、一式两份。

### 5. 场地证明（三种，按实际择一或并用）
- **产证复印件**（自有场地）
- **房租租赁合同**（租赁，注意**合同期限要覆盖办学周期**）
- **无偿使用证明**（他人无偿提供，须产权方出具）

> **坑**：合同期限太短（如只剩半年）会被质疑办学持续性；产证用途与培训用途不符要提前确认。

## 三、职业设置标准（门槛表）看什么

各地下发的《职业设置条件（试行）》结构基本一致，逐条核这几项：

| 项 | 看什么 | 示例（人工智能训练师·上海试行标准） |
|---|---|---|
| **班规模** | 按多少人/班制定、上限多少 | 按 30 人/班制定；**原则上不超过 50 人/班**；超员须增配教师与设备 |
| **师资人数** | 理论课、实训课各至少几人 | 理论课专/兼职教师 ≥3 人；实训指导教师 ≥3 人；两者可兼用 |
| **从教资格** | 二选一：教师资格证 / 企业经历 | 人社或教育部门核发的教师资格（上岗）证；**或**企业兼职讲师有 3 年以上本行业工作经历 |
| **从业经历** | 教学年限或企业年限 | 院校/培训机构相关课程教学 2 年以上；**或**相关企业技术岗 3 年以上 |
| **理论场地** | 座位数与配套 | 30 座以上标准教室，配多媒体、局域网、百兆以上带宽 |
| **实操场地** | 同时实训人数 | 至少满足 30 人以上同时实训；光线通风卫生良好 |
| **设备** | 按角色分别列最低配置 | 服务器（CPU 型/GPU 型）全校数量下限、教师机每教室 1 台、学生机每教室 ≥30 台，逐项列 CPU/内存/硬盘/网卡参数 |
| **软件** | 实训所需平台与框架 | 支持数据获取与标注实训；支持 Jupyter Notebook 与主流开源框架（TensorFlow / PyTorch） |
| **教学资料** | 必备教材与标准 | 《<职业>国家职业技能标准》＋配套培训教材 ＋ 其他领域资料 |
| **环境** | 安全、照明、消防、通风 | 教室人均面积保证安全舒适；供电照明完备；照明、消防、安全、通风符合国家标准 |

> **用法**：把这张表当**访谈提纲**——每格问「我们这项够不够」，不够就先补，别等材料报上去被打回。**不要照抄上面示例的数字**，你得拿属地下发的当期标准来对。

## 四、装包前的最后一遍自检

```
□ 申请报告抬头＝属地区人社局，七栏齐全，市场数据标了出处
□ 每个等级各一张申请表，封面编号规则已按属地要求填
□ 设备清单逐条标了适用等级；师资表逐人一行且电话/单位与教师材料一致
□ 每位教师七件齐全，身份证/合同/简历三处信息一致
□ 场地证明的合同期限覆盖办学周期
□ 教学文件三件齐全，教材为正版公开出版物
□ 职业设置标准逐条对照过，不达标项已补或有补的排期
```
