# 职业技能等级认定培训机构 · 成立全流程（vocational-training-school-setup）

> 一个**手把手**带你走完「从想办 → 办成」的 AI 技能包。
> 先判走哪条路，再**一门一门**过；每门都说清「进门要什么 · 做什么 · 出门交什么 · 谁动手 · 过不了怎么办」。
> 版本：**2.0.0** · 许可：MIT

---

## 一、它解决什么问题

办培训学校的坑不在「不会填表」，在于**顺序不能错、通道不能混**：

- **先有培训资质，才能招生**——未取得办学许可证或未经依法登记，不得面向社会开展职业培训活动；
- **两证齐备才算真的能开课**——办学许可 ＋ 法人登记；
- **消防、场地、师资、验资要提前确认**——装修完才发现场地不合规，是最贵的错；
- **「能办学」≠「能发证」**——对外发职业技能等级证书是**另一套资质**（社评组织备案）；
- **「职业培训」≠「校外培训」**——面向**中小学生**的培训归**教育／体育**部门，与人社这条通道**完全两套**；
- **各地口径不一样**——同一省内不同县市的面积、资金、时限门槛都可能不同。

## 二、它长什么样（手把手）

```
总入口（说一句话，自动分流）
├── 手把手主线   skills/run-through/    ★先判路（A/B/C）→ 一次一门 → 五问卡
├── 口径与路线   skills/scope-route/    锁属地口径（审批机关/依据/来源）＋定资质路线
├── 推进表核对   skills/gap-check/      跑 scripts/gap_check.py；认不出就拒答
├── 交付物清单   skills/deliverables/   逐项打勾＋标证据位置＋常见退回原因
├── 运行合规     skills/compliance/     年检、台账、培训协议、收费公示、变更与终止
└── 评价资质     skills/evaluation/     社评组织遴选备案（须点名，不得与办学许可混称）
```

**第 0 步 · 三问定路**

| # | 问 | 是 → | 否 → |
|---|---|---|---|
| 1 | 已有《办学许可证》＋法人登记吗？ | **主线 B** 新设职业（工种） | **主线 A** 从零新办机构 |
| 2 | 要对外发职业技能等级证书吗？ | 再进**评价资质**（须点名） | 不进出口 |
| 3 | 培训对象是**中小学生**吗？ | **停**——校外培训另一套体系 | 继续 |

**主线 A（八门）**：立项与路线 → 名称核准 → 筹设 → 正式设立 → 审查许可 → 法人登记 → 开办配套 → 依法运行
**主线 B（五门）**：主体与范围 → 定职业等级 → 组申报包六大类 → 报送审查 → 获批纳管

每门固定五问卡，见 `references/执行主线.md`。

## 三、三条铁律

1. **以属地当期公开文件为准。** 培训类审批按区/县级人社部门执行。技能里的湖北、上海两份口径**只作对照与提问用**，落地前必须取当地当期办事指南原文。
2. **两种资质别混。** **办学许可**（能办学）≠ **社评组织备案**（能发等级证书）。
3. **两条通道别混。** **人社·职业技能培训**（成年人）≠ **教育/体育·校外培训**（中小学生）。出现「中小学生」即停手，不代做、不混装。

## 四、机器帮你干 / 必须你本人干

**机器全包**：判路与逐门推进卡 · 属地口径对照 · 推进表机械核对 · 交付物逐项打勾 · 缺口与催补清单 · 申报包结构配方 · 年检与台账排期 · 评价资质条件对照。

**必须你本人来**（11 项）：取属地当期原文 · 名称实名申报 · 场所与消防核实 · 验资与固定资产证明 · 教师劳动合同与证书原件 · 单位盖章 · 本人签字 · 提交申报 · 缴费 · 现场考察/答辩到场 · 领取证照。

> 判断标准：**凡是要盖章、要签字、要扫码、要花钱、要到现场的，机器不代办。** 明细见 `references/人工把关点.md`。

## 六、脚本用法

```bash
python scripts/gap_check.py --xlsx "<推进表.xlsx>" --region 湖北 --show-headers --json-out gap.json
```

- 需要 `openpyxl`；**请在虚拟环境或已装 openpyxl 的解释器中运行**，脚本不会自动安装任何依赖。
- 只读你的表，只在给了 `--json-out` 时写一个 JSON；**不联网、不删文件**。
- 退出码：`0` 无阻断 ｜ `1` 存在阻断 ｜ `2` 文件/依赖问题 ｜ **`3` 未识别到可核对的表（拒答）**。
- **认不出就拒答**：绝不把「没认出来」当成「全都没有」。支持真实列名别名、两行复合表头、按季度铺开的矩阵表、空模板识别。

## 八、免责与边界

- 本技能**不代替审批部门解释政策**，**不承诺**办理结果、补贴金额、评审通过。
- 政策类数据一律回官方原文核，**不套模板、不照抄其他地区数字**。
- 案例与口径中的一切阈值**只作提问清单**，不作为属地标准。
- **不代做**校外培训（中小学生）通道的申报包。
- 对外材料**不含**主体名、客户名、地名绑定、人名、证件号。
