# opc-service · 教学服务交付

## 适用场景

课程已成交，进入**交付期**，需要保证到课率、作业完成率与学习体验稳定时使用。

## 输入

- `cohort`：班级/学员名单与开课时间、课时安排。
- `syllabus`：大纲与每次课的产出目标。
- `roles`：主讲、助教/班主任分工。
- `signals`：到课、作业、答疑响应等已有数据（没有则从零采集）。

## 步骤

1. **开班准备**：开课前 48 小时完成建群、发课表、发学习指引、确认设备；逐人确认首课时间。
2. **课堂服务**：每课固定「签到 → 目标 → 讲解 → 练习 → 小结 → 下次预告」六段，课后 2 小时内发回放与作业。
3. **学习跟进**：对「连续缺课 1 次／作业连续缺交 2 次／答疑超时」三类信号，24 小时内一对一跟进。
4. **质量控制**：每周抽 1 次课做满意度微调研（3 题以内），把差评项转成下周改进项。
5. **结课交付**：完成结课产出验收、发放证书/作品集，并沉淀 2 条可公开的学员成果（须授权）。

## 输出

- 一份开班检查清单（逐项打勾）。
- 一份每周学情跟进表（信号 → 动作 → 结果）。
- 结课交付清单与成果素材。

## 边界

- 学员个人信息与成绩属敏感数据，只在必要范围内使用（W-09 精神）。
- 学员成果对外发布须取得授权，不得虚构。
