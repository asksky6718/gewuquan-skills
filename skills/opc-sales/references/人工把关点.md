# 人工把关点（opc-sales）

机器做不了的列清楚、提前准备好、一次交接完。销售环节的特殊性：价格是钱、合同是法律责任——一律留人。

## 一、完全不用人操心的（机器全包）

| 事项 | 机器做到哪一步 |
|---|---|
| 硬前提核验 | `lead.json`／`course.json` 缺任一即拒 |
| 话术匹配 | 按产品分级（B1–J1）取对应话术与「一指禅」材料 |
| 资质齐备校验（DE-1） | 办学许可／ICP／证书等级逐项核对 |
| 合同编号校验（DE-2） | 存在性与格式 |
| 审批留痕核验（DE-3） | `approval_channel`／`approval_by`／`approval_at` 三项齐全性 |
| 三件套输出 | `order.json` ＋ `order.md` ＋ `order-report.html` |

## 二、必须本人上手的（五项，一个都不能少）

| # | 动作 | 为什么躲不掉 | 机器提前准备好什么 | 人做完回什么 |
|---|---|---|---|---|
| 1 | 报价、折扣、账期的审批 | 涉钱，判定权在人 | 报价草案 ＋ 历史成交对照 | 审批留痕（谁批／何时） |
| 2 | admin 档录入审批 | 留痕必须走有效身份 | 录入表单预填 | 录入确认 |
| 3 | 合同盖章与签署 | 法律效力 | 合同文本（主体合同模板库）＋ 签署要点卡 | 签署版扫描件 ＋ 合同编号 |
| 4 | 资质原件核验 | 复印件不可信 | 资质清单与有效期提醒 | 核验结论 |
| 5 | 对外承诺（交付期／效果口径） | 涉对外 | 承诺草案与边界话术 | 审批留痕 |

**没有审批留痕的订单，机器拒收——这是本 skill 最硬的一道门。**
