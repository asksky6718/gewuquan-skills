# opc-sales · 销售转化

## 适用场景

已有咨询线索，需要把线索稳定推进到**体验课 → 成交**，避免「加了微信就沉默」时使用。

## 输入

- `lead`：线索来源、年级/职业、已知需求、预算区间（可空）。
- `offer`：可售课程／服务与当期政策（价格、课时、赠品、退费规则）。
- `stage`：当前阶段（未加微／已加微未聊／已聊未到课／已到课未成交）。

## 步骤

1. **24 小时首触**：留资后 24 小时内完成首次沟通，目标只有一个——约到体验课或明确下次沟通时间。
2. **需求确认（提问优先）**：用 3 个问题确认「目标—现状—障碍」，把答案写回线索卡，不急着讲产品。
3. **价值对齐**：按确认的需求只讲 1–2 个最相关的卖点，用「同类学员案例」增强可信度。
4. **异议处理**：对「贵／没时间／再看看／不信任」四类异议，各准备「认同 → 澄清 → 证据 → 小步承诺」四步话术。
5. **成交动作**：给出**当日可执行的下一步**（锁定体验课时间／发报名链接／约 1 对 1），
   到期未回复按 1／3／7 天节奏二次触达，仍无响应则转培育池并标注原因。

## 输出

- 每人一张跟进卡（阶段、下次动作、时间、障碍）。
- 一张异议处理话术表。
- 当日待办清单（谁、做什么、什么时候）。

## 边界

- 不做虚假承诺、不诱导贷款、不承诺与政策不符的退费条件。
- 涉及金额的让价与合同条款以公司授权口径为准，超出授权须升级决策（W-02）。
