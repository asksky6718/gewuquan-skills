# 课件生成流水线与配额

## 一、生成机制（碎片化生成）

```
输入主题/大纲/学习目标
   ↓
① 提炼知识点清单  → 独立校验正确性（未通过自动修正）
   ↓
② 逐知识点生成课堂内容（禁止一次性生成长课时）
   ↓
③ 组合成完整课程  → 自动保存到「我的课件」
```

- **为什么分次**：一次性生成长课时的质量不可控，平台强制按知识点分次生成。
- **耗时**：视内容复杂度，通常数分钟；分阶段可见「大纲 → 角色 → 页面内容」。

## 二、产出形态

| 形态 | 说明 |
|---|---|
| 互动课堂 | 含角色、页面内容、交互（测验 / PBL） |
| 我的课件 | 服务端落库；刷新/重进可恢复，**不重复扣配额** |
| 静态播放地址（`liveUrl`） | 发布到 OSS 后获得；**仅白名单域名可嵌入** |
| 网校课时 | 后台创建课时后，挂到目标网校课程（courseId）下，可 iframe 播放 |

## 三、配额口径

| 项 | 口径 |
|---|---|
| 计费单位 | Token（按实际用量 usage 扣减） |
| 新用户 | 审核通过后默认获得基础额度（以平台当期政策为准） |
| 申请档位 | 多档（如 100 万 / 300 万 / 1000 万），提交后**管理员审核发放** |
| 用尽表现 | 生成提示「剩余 0」 |
| 重新生成 | **会再消耗**配额 |

## 四、写作要点（提高生成质量）

- 输入按**三段式**：`主题 ＋ 目标人群 ＋ 关键知识点`；
- 例：`人工智能训练师三级备考 · 职业道德与表格基础`；
- 备考类内容建议**绑定已在平台组织的题库知识点**，避免凭空造知识点。

## 五、边界

- **内容合规由负责人判断**，平台机制只保证生成可用，不背书内容口径；
- 生成结果**不直接对外发布**；对外前须经负责人过目。
