# 供应商标与本配置要点

> 位置：`/admin` → **系统运维 → 系统设置** → 按能力分类选择供应商。
> **Key 由使用者本人写入**；本文件只记录「配哪些字段、怎么算配好」。

## 一、能力分类位（实测存在）

| 分类 | 说明 |
|---|---|
| **视频生成** | 文生视频/图生视频类供应商 |
| 图像生成 | 文生图/图像编辑类 |
| 语音合成 | TTS 配音类 |
| 语音识别 | ASR 类 |
| 文档解析 | 文档抽取类 |
| 网络搜索 | 联网检索类 |

> 每个分类下**可有多个供应商位**，未配置的为空是正常态。

## 二、配置三要素

| 字段 | 填什么 | 谁填 |
|---|---|---|
| Base URL | 供应商的 API 基址 | 使用者 |
| 模型 | 供应商标识的模型名 | 使用者 |
| API Key | 供应商密钥 | **使用者本人**（技能不代填） |

## 三、判定「配好了」三步

1. 点**「连接测试」** → 成功提示（例：`视频服务连接成功`）；
2. **保存**；
3. **刷新页面回看** → 配置仍在。

> 三步缺一不可：**只测不存、只存不刷新回看**，都不算配好。

## 四、已配置实例（示例）

| 能力 | 供应商 | Base URL | 模型 | 验证 |
|---|---|---|---|---|
| 视频生成 | 阿里云百炼 | `https://dashscope.aliyuncs.com` | `happyhorse-1.0-t2v` | 连接测试通过 · 跨刷新留存（2026-10-13） |

## 五、其它视频供应商位（实测为空，仅供参考）

Seedance / 可灵 / Veo / Sora / MiniMax / Grok Video 等位置存在但**均可为空**。
**以控制台实际下拉为准**；本表不构成"必须配置"的要求。

## 六、坑

| 坑 | 处置 |
|---|---|
| 连接测试通过但刷新后没了 | 未点击保存，或保存失败 → 重做三步 |
| 模型名写错 | 用供应商标识的**准确模型名**；不确定时在供应商控制台核对 |
| Key 有额度但测试失败 | 核对 Base URL 是否为该供应商的**正确基址**（不同地域端点不同） |
| 把 Key 贴在对话里让技能代填 | **禁止** —— 一律由使用者本人写入 |
