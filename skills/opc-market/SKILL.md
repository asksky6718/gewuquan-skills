# opc-market · 市场部

> **保密级别：内部件 · 禁止对外发布**（技能生产总纲定级）。
> **v2.0.0 主线**：营销环节以**智能体＋自媒体**为主要手段——智能体负责量产与盯梢，人负责露脸与承诺。

## 定位与边界

| | 内容 |
|---|---|
| **本 skill 干什么** | 智能体×自媒体获客 → 触点事件 → `lead.json`（线索），并打 OPC 级别标签 |
| **上游** | 无（**流水线起点**）——这是「上游是下游硬前提」链的第一环 |
| **下游** | `opc-sales`（销售部）吃 `lead.json` |
| **不做** | 不报价、不承诺、不签单（销售部／人类决策者的活）；不生成课程（产品部的活）；不代运营人类实名账号（见人工把关点） |

## 能力总览

| 能力 | 做什么 | 入口 |
|---|---|---|
| **自媒体获客引擎** | 智能体分工跑内容流水线：选题 → 初稿 → 合规审 → 人审 → 发布 → 互动盯梢 → 触点登记 | `skills/media-engine/SKILL.md` |
| **线索受理** | 触点事件归集（鱼塘模型）→ 打标（有证据自动、无证据挂人工）→ `lead.json` → 5 道门校验 → 三件套输出 | `skills/lead-intake/SKILL.md` |

## 路由判定表

| 用户这样说 | 前置门禁 | 进入 | 明确不要做 |
|---|---|---|---|
| 「下周发什么内容」「这条视频脚本写一下」「评论区有人问课程」 | 无 | `media-engine` | 不用人类实名账号自动发布；不承诺效果 |
| 「这条私信怎么登记成线索」「活动名单导进来」「给这批线索分级」 | 无 | `lead-intake` | 无证据不猜级别；联系方式不入共享库正文 |
| 「这个人报价多少」「能不能便宜」 | — | **停**：转 `opc-sales` | 本 skill 不谈价 |

## 通则

- **线索一条一记录**：字段契约见 `references/lead-fields.md`；改字段先改流水线契约，再同步本包，两处一致。
- **级别标尺**：OPC 九级标尺由装配层运行时注入（`--ladder` 参数），**本包不内置**——避免出现第二份权威源。
- **联系方式属个人信息**：只入主体库，不入共享库正文；对外材料只出现当前主体名。
- **智能体与人的分工铁线**：量产、盯梢、归因给智能体；露脸、承诺、花钱投放给人类。
- **交付末块统一**：各子技能交付回复的末块标题一律「交付后请确认」。

## 环境与约定

- 校验器只用 Python 标准库，不联网、不装包、不调模型；自测 `python tools/selftest.py`。
- 主体名册与九级标尺均由装配层运行时注入（`--registry`／`--ladder`），本包不内置。
- 内容素材（渠道数据、历史转化）由调用方提供；本包不采集、不外传。
