# opc-market · 市场部技能（v2.0.1）

> 用**智能体＋自媒体**做招生获客：智能体量产内容、盯梢互动，把各平台触点收敛成带级别标签的招生线索，5 道门机判后才放行。
> 版本：**2.0.1** · 许可：MIT

---

## 一、它解决什么问题

培训机构获客的老三样坑：

- 内容靠人憋——一周憋不出三条，发布断断续续，账号养不起来；
- 私信、评论、活动名单散在各处——谁有意向、意向多深，没人说得清；
- 线索登记全凭感觉——「感觉能成」和「真能成」之间差着一张可核对的表。

这个技能把营销拆成两条机器流水线：**内容流水线**（选题→初稿→合规预审→排期）和**线索流水线**（触点→归集→打级别标签→5 道门校验），机器做完 90%，剩下的 10%（发布、花钱、对外承诺）提前列清楚等本人动手。

## 二、它长什么样

```
opc-market（根路由：说一句话自动分流）
├── skills/media-engine/   内容引擎：智能体七岗流水线
│     选题 → 写稿 → 合规审 → 【人终审】 → 排期 → 【人发布】 → 盯梢归因
├── skills/lead-intake/    线索受理：触点 → lead.json（L1–L9 级别标签）
├── references/
│     ├── 自媒体获客打法.md   8 渠道对照 · 智能体分工矩阵 · 内容日历 · 效果三口径
│     ├── 人工把关点.md       9 项机器全包 + 7 项必须本人
│     └── lead-fields.md      线索字段契约（与流水线契约对齐）
└── tools/
      ├── lead_check.py     5 道门真校验器（IN-1…IN-5，纯标准库）
      └── selftest.py       12 个击穿用例自测
```

**级别标签（L1–L9）**与公司能力分级共用一把尺子：有考试分数、作品、方案等证据的自动定级（记 `auto_with_evidence`）；没证据的**不猜**，挂人工补证据或人工定级。

## 三、怎么用

对话里直接说人话，不用记命令：

| 你想干什么 | 这样说 |
|---|---|
| 排下周内容 | 「下周发什么内容」「给我排个内容日历」 |
| 写一篇 | 「给抖音写条短视频脚本，主题是××」 |
| 审一遍合不合规 | 「这篇稿子合规审一下」 |
| 登记一条线索 | 「这条私信登记成线索」「把这次活动名单归集一下」 |
| 看线索质量 | 「这批线索都什么级别」「哪条不过校验」 |
| 复盘效果 | 「这周自媒体数据怎么样」 |

命令行校验（可选，适合批量）：

```bash
# 5 道门校验：不过不放行
python tools/lead_check.py validate lead.json --registry 名册.json

# 出人读版报告
python tools/lead_check.py render lead.json --md

# 自测 12 个击穿用例
python tools/selftest.py
```

## 四、安装

```bash
cp -r opc-market ~/.workbuddy/skills/     # WorkBuddy
cp -r opc-market ~/.codex/skills/         # Codex 系
```

装好后说「市场部」「招生获客」「自媒体获客」即可唤起。需要 Python ≥ 3.10（仅校验器用到，不联网、不装包）。

## 五、机器干 ／ 人来干

**机器全包 9 项**：选题清单 · 内容初稿 · 合规预审 · 发布排期 · 评论私信盯梢 · 触点归集 · 有证据自动定级 · 5 道门校验 · 三件套输出（`lead.json`＋`lead.md`＋`lead-report.html`）。

**必须本人 7 项**：平台账号实名认证 · 内容终审并点发布 · 直播出镜 · 付费投放开通充值 · 对外合作承诺 · 无证据线索的人工定级 · 客户个人信息处置确认。

判断标准同全仓库：动作做错了撤不回、或涉及钱、对外承诺、实名资产 → 必须人做。

## 六、硬红线

```
1  机器不碰人类实名账号 —— 发布永远由账号实名人亲手点
2  不出禁语 —— 保过/包过/通过率/挂靠/押题等表述一律预审拦截
3  无证据不定级 —— 线索级别必须有证据指针或人工判语
4  校验不过不放行 —— 5 道门全绿才进销售环节
5  付费投放与对外承诺须人类逐次审批
6  客户联系方式只入主体库，导出共享须本人确认
```

## 七、上下游

- **本技能是流水线起点**：上游无产物即拒（自己就是源头）。
- **下游**：线索 `lead.json` 交给 `opc-sales`（订单）、`opc-product`（按目标级别产课）。
- 售后部判定晋级后，`next_level_course` 信号会**回流**到本技能做复购。
