# opc-market · 市场获客

## 适用场景

一人公司（OPC）或小团队教育业务，需要以最低成本持续获得**有效咨询线索**时使用。
输入一次「现状＋目标」，输出一份可直接执行的获客周计划。

## 输入

- `offer`：在卖的课程／服务是什么，解决谁的问题。
- `audience`：目标人群（学段／职业阶段／地域／付费能力）。
- `budget`：本周可投入的预算与时间（钱与小时二选一亦可）。
- `history`：过去 4 周各渠道线索量与成交率（没有就写「无」）。

## 步骤

1. **画像收敛**：把 `audience` 收敛成 1 个主画像 ＋ 1 个备选画像，写清「他们此刻最痛的一件事」。
2. **渠道盘点**：在「自然内容（短视频／图文／社群）／转介绍／平台投放／异业合作」四类里，
   按「单位线索成本 × 可复制性」排序，只保留 2 个主渠道。
3. **内容选题**：每个主渠道排 5 条选题，标题＝「痛点场景 ＋ 具体结果 ＋ 时间承诺」，禁止空泛口号。
4. **转化路径**：明确「看到 → 私信/留资 → 加微 → 体验课 → 成交」每一步的钩子与话术要点。
5. **复盘口径**：固定每周同一时间记录「曝光／留资／加微／到课／成交」五档数字，
   计算线索成本与到课率；连续两周无效的选题停掉。

## 输出

- 一张目标画像卡（人群、痛点、支付动机）。
- 一张主渠道 × 5 选题的排期表（含钩子）。
- 一条转化路径与五档复盘指标定义。

## 边界

- 不承诺「保过／保分／保就业」等违规结果（招生宣传红线）。
- 不代替销售承诺价格与退费政策；价格与政策以 `opc-product`／`opc-sales` 口径为准。
