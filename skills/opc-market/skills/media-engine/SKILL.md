# media-engine · 自媒体获客引擎

## 用途

以智能体＋自媒体为主要营销手段：智能体量产内容、盯梢互动、归因渠道；人负责露脸、终审与承诺。产出统一收敛为**触点事件**，交 `lead-intake` 受理。

## 何时用

- 「下周发什么内容」「这个主题怎么写」——选题与写稿岗。
- 「这条内容能不能发」「有没有违规表述」——合规审岗（预审）＋提醒终审人。
- 「评论区／私信有人问课程」——盯梢岗出回复草稿＋登记触点。
- 「这周数据复盘」——数据岗周报＋下周选题输入。

## 输入

| 输入 | 必填 | 说明 |
|---|---|---|
| 渠道清单 | 是 | 本主体开通并完成认证的平台（未认证平台不投放教育内容） |
| 历史内容与数据 | 否 | 有则回填渠道对照表，选题更准 |
| 本主体话术口径 | 是 | 对外材料只出现当前主体名与口径 |

## 步骤

1. **选题**：按 `references/自媒体获客打法.md` 渠道对照表，每渠道出 ≥3 条选题卡（主题／渠道／理由／预期触点）。
2. **写稿**：一稿一出处——不编数据、不编案例；引用必须带出处。
3. **合规预审**：逐条扫禁语（保过／包过／通过率／挂靠／押题／冒用案例），出预审记录与修改建议。
4. **人终审**：交账号实名人终审并点发布——智能体**不代发布、不碰人类实名账号**。
5. **排期**：按渠道流量时段排周历，生成发布队列。
6. **盯梢**：评论／私信汇总出待回复清单与回复草稿；意向信号登记为触点事件草稿。
7. **归因**：触点 → 渠道唯一归因 → `lead.json` 草稿，转 `lead-intake` 校验。

## 护栏

- **三个一律不**：不自动发布、不承诺效果、不外发客户个人信息。
- 花钱投放（预算／充值）与对外合作承诺：出方案，**留人拍板**。
- 直播出镜与真人露脸环节只出脚本与预案，不代出镜。
- 内容引用学员案例须本人书面同意，否则不用。

## 产出物

- 周发布队列（选题卡＋终稿＋排期）。
- 待回复清单＋回复草稿。
- 触点事件草稿（交 `lead-intake`）。
- 周复盘（触点数／有效线索率／级别分布三口径）。
