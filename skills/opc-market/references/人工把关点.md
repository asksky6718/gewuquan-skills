# 人工把关点

目标：**能机器做的全交给机器，机器做不了的列清楚、提前准备好、一次交接完**。
营销环节的特殊性：账号是实名资产、承诺是法律责任、投放是真金白银——这三类一律留人。

## 一、完全不用人操心的（智能体全包）

| 事项 | 智能体做到哪一步 |
|---|---|
| 选题 | 按渠道热点与历史转化数据出下周选题清单（每渠道 ≥3 条，附选题理由） |
| 初稿 | 短视频脚本、图文、公众号长文、评论回复模板，一次产出一周量 |
| 合规预审 | 逐条扫「保过／包过／通过率／挂靠／押题」等禁语与夸大表述，出修改建议 |
| 发布排期 | 按各渠道流量时段排出周历，生成待发布队列 |
| 评论与私信盯梢 | 汇总待回复清单，出回复草稿；意向信号自动登记为触点事件 |
| 触点归集 | 活动／私信／评论／转介绍事件 → 标准字段 → `lead.json` |
| 级别打标（有证据） | 有考试分数／产物／方案证据的，自动定级并记 `auto_with_evidence` |
| 5 道门校验 | `lead_check.py` 机械校验，不过不放行 |
| 三件套输出 | `lead.json` ＋ `lead.md` ＋ `lead-report.html` |

## 二、必须本人上手的（七个，一个都不能少）

| # | 动作 | 为什么躲不掉 | 智能体提前准备好什么 | 人做完回什么 |
|---|---|---|---|---|
| 1 | 平台账号实名注册与企业认证 | 实名认证绑定身份证与人脸核验，平台只认本人 | 各平台认证材料清单 ＋ 入口指引 | 一句「已认证」 |
| 2 | 内容终审并点「发布」 | 账号封禁风险与品牌口径由账号实名人担责；智能体预审不代替终审 | 终稿 ＋ 合规预审记录 ＋ 发布排期卡 | 发布时间 ＋ 链接 |
| 3 | 直播出镜与真人露脸 | 平台对教育类内容普遍要求真人出镜，信任转化靠人 | 直播脚本 ＋ 互动问答预案 | 场次记录 |
| 4 | 付费投放的开通与充值 | 花钱事项（人类审批门） | 投放计划（预算／定向／素材）＋ 预期口径 | 审批留痕 ＋ 充值金额 |
| 5 | 对外合作与渠道承诺 | 对外承诺须人类逐次放行（涉钱／对外） | 合作条款草案 ＋ 收益分成测算 | 审批留痕 |
| 6 | 级别人工定级 | 无证据的线索**不猜**：挂人工补证据或人工定级 | 待定级清单 ＋ 补证据问题清单 | 定级结论 ＋ 定级人 |
| 7 | 客户个人信息处置确认 | 联系方式只入主体库；导出、共享、外发须本人确认 | 待确认清单（谁／哪些字段／给谁） | 确认留痕 |

## 三、回交凭据最小要求

- 发布类：平台名 ＋ 内容标题 ＋ 发布时间 ＋ 链接（或截图）。
- 投放类：计划编号 ＋ 预算 ＋ 审批留痕（谁批的、何时）。
- 定级类：定级人 ＋ 级别 ＋ 依据（证据指针或人工判语）。
- 信息处置类：确认人 ＋ 时间 ＋ 处置范围。

**没有凭据的回交，按未做处理**——与全团队「不采信『已完成』自述」同一纪律。
