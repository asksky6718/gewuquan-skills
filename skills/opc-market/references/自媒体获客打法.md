# 自媒体获客打法（智能体 × 自媒体）

> v2.0.0 新增。定位：营销环节的**主手段**是智能体＋自媒体——智能体负责量产与盯梢，人负责露脸与承诺。
> 本页是 `media-engine` 子技能的内容底册；渠道效果数据回填后按周迭代。

## 一、总原则（三条铁线）

1. **量产给智能体，露脸给人**：脚本、图文、评论草稿、排期，智能体一周产一批；出镜、直播、终审发布，必须真人。
2. **只引不诺**：内容只讲「能帮什么、怎么开始」，不讲「保过、包会、通过率、挂靠、押题」——预审智能体逐条扫禁语，终审人二次把关。
3. **触点必登记**：任何私信、评论、留资、转介绍，一律登记为触点事件进 `lead.json`；没有触点登记的内容，效果口径视为零。

## 二、渠道对照表（按优先级）

| 渠道 | 内容形式 | 智能体分工 | 人做什么 | 转化触点 | 适用阶段 |
|---|---|---|---|---|---|
| 短视频（行业知识口播） | 30–60 秒口播脚本 | 选题＋脚本＋合规预审＋字幕规格 | 出镜拍摄＋终审发布 | 评论区＋私信 | 起量主力 |
| 直播（答疑型） | 每周 1 场，主题答疑 | 主题＋脚本＋互动问答预案＋场记 | 出镜主持 | 直播间私信＋加群 | 信任转化 |
| 公众号（长文沉淀） | 方法论长文、案例拆解 | 初稿＋配图建议＋排版 | 终审发布 | 菜单留资＋后台留言 | 私域沉淀 |
| 知乎（问答卡位） | 行业问题专业回答 | 找问题＋答稿＋合规预审 | 终审发布 | 评论区＋私信 | 精准流量 |
| 短视频（生活方式种草） | 场景化短内容 | 选题＋脚本 | 出镜 | 评论区 | 泛流量试投 |
| 社群（企微／微信群） | 日常运营＋活动 | 话术库＋活动方案＋群公告草稿＋盯梢汇总 | 群主身份发关键消息 | 群内私信＋接龙 | 转化与复购 |
| 转介绍 | 老带新活动 | 活动方案＋话术＋追踪表 | 活动拍板（涉对外承诺） | 会员服务／学员推荐事件 | 低成本高转化 |
| 行业活动／协会 | 展会、沙龙、赞助 | 物料清单＋跟进话术＋名单归集 | 出席＋商务洽谈 | 活动名单 | B 端线索 |

## 三、智能体分工矩阵（一条内容流水线，七个岗位）

| 岗位 | 干什么 | 产出 | 边界 |
|---|---|---|---|
| 选题岗 | 渠道热点＋历史转化 → 下周选题清单 | 选题卡（主题／渠道／理由／预期触点） | 不定预算 |
| 写稿岗 | 选题卡 → 初稿（脚本／图文／回答） | 初稿 ＋ 自检清单 | 不编数据、不编案例；引用须有出处 |
| 合规审岗 | 逐条扫禁语与夸大表述 | 预审记录 ＋ 修改建议 | 只提建议，不代替终审 |
| 排期岗 | 初稿 → 周发布历（按渠道流量时段） | 发布队列 | 不执行发布 |
| 盯梢岗 | 评论／私信汇总 ＋ 回复草稿 ＋ 意向识别 | 待回复清单 ＋ 触点事件草稿 | 不用人类账号自动发送 |
| 归因岗 | 触点 → 渠道来源唯一归因 → `lead.json` 草稿 | 触点事件记录 | 联系方式只入主体库 |
| 数据岗 | 周复盘：曝光／私信／留资 → 渠道对照表回填 | 周报 ＋ 下周选题输入 | 不自行改打法 |

**流水线顺序**：选题 → 写稿 → 合规审 → **人终审** → 排期 → **人发布** → 盯梢 → 归因 → `lead-intake` 校验。

## 四、内容日历（最小可跑版）

| 周期 | 动作 |
|---|---|
| 每周一 | 选题岗出清单 → 人勾选 |
| 周二至周四 | 写稿＋合规审 → 人按日终审发布（短视频 3 条／知乎 1 答／公众号 1 篇） |
| 每周三或五 | 直播 1 场（人出镜） |
| 每日 | 盯梢岗出待回复清单 → 人或授权话术回复 → 意向登记 |
| 每周五 | 数据岗周复盘 → 回填渠道对照表 → 定下周选题 |

## 五、效果口径（只认这三个数）

1. **触点数**：登记进 `lead.json` 的触点事件条数（按渠道分组）。
2. **有效线索率**：通过 5 道门校验的线索 ÷ 触点总数。
3. **级别分布**：L1–L9 各级线索占比（无证据挂人工的不计入分布，单列「待定级」）。

**不做虚荣口径**：阅读量、播放量只作参考，不进周报结论。

## 六、合规红线（预审岗逐条扫，终审人最后把关）

| 红线 | 说明 |
|---|---|
| 禁承诺 | 不出现「保过／包过／不过退费（无依据）／通过率 XX%／押题命中率」 |
| 禁挂靠 | 不宣传证书挂靠、人证分离 |
| 禁冒用 | 不用非自有案例与客户名；学员案例须本人书面同意 |
| 个人信息 | 评论区与私信里的手机号／微信号，只入主体库，不入共享库正文 |
| 平台规则 | 教育类内容按各平台资质要求先行认证；未认证平台不投放教育内容 |
| 商标与话术 | 对外材料只出现当前主体名与当前主体话术口径 |
