# 口径来源 · zhicheng-material

> 本文件说明 `references/rules.json` 里每一条清单项的**出处**与**当前口径边界**。
> 一句话：**出处全部来自知识库已核验存在的条目，标题逐字引用，不编造、不用内部资料顶替。**

## 一、出处清单（知识库原始条目标题）

| evidence_id | 原始条目标题（逐字） | 本技能用到它的地方 |
|---|---|---|
| `zhicheng_levels` | 人工智能训练师能报几级？各级申报条件是什么？ | 学历 / 学籍证明、工作年限证明、已有职称证书；等级专属项（下一级职业技能等级证书、初级职称证明）；逐级申报口径说明 |
| `zhicheng_channel` | 找谁报？三类评价通道怎么选？ | 申报表与个人承诺、单位自主评价备案 / 岗位考核材料、在校学籍证明；三类通道差异说明 |
| `zhicheng_verify` | 评价机构资质怎么核验？ | 评价机构资质核验记录、当期评价计划与缴费凭证 |
| `zhicheng_subsidy` | 技能提升补贴能领多少？ | 技能提升补贴申领材料（可选） |
| `zhicheng_certquery` | 证书怎么查询？有哪些特性？ | 已有职业技能等级证书 |

- 上述标题是知识库条目的**原始标题**；`rules.json` 的 `evidence` 字段按 `id → 标题` 登记，引擎据此在清单项上标注「知识库条目《…》」。
- `rules.json` 里 `evidence_id` 为 `null` 的清单项（身份证明、业绩 / 成果材料）为**通用受理要件**：知识库未单列，页面与结果统一标注「本条库里没有单列，以评价机构当期要求为准」，**不编造出处**。

## 三、来源边界（重要）

1. **只用知识库已核验条目**：本技能引用的标题均为知识库中已存在、可检索命中的条目；不引用任何内网文件、内部资料、个案结论或未公开材料。
2. **标题逐字引用**：条目标题按知识库原始标题登记，不改写、不拼接、不使用近似标题。
3. **未单列就说没有**：知识库未单列的通用受理要件，一律标注「本条库里没有」，**不得**用其他文件或记忆中的说法顶替出处。
4. **口径会变**：评价机构当期公告、属地人社部门当期评价计划与补贴政策可能调整；清单只作准备参考，**能否报、报哪一级、补贴金额与时限以评价机构与属地人社部门当期核定为准**。
5. **不承诺结果**：本技能不出「保过」「包过」类承诺话术，也不对报名受理、资格认定或通过与否作任何结论。
6. **人不被机器替代**：真实性、完整性核对，以及签字、盖章、提交、缴费等动作，均由本人完成，见 `人工把关点.md`。

## 四、规则维护

- 清单项、出处映射与说明的唯一事实源是 `references/rules.json`；本文件只作人读说明。
- 新增或调整清单项时，应能指向一条**知识库已核验存在的条目标题**；无法指向的，按通用受理要件处理并标注「本条库里没有」。
- 规则更新即升版本，并同步 `VERSION` 与 `CHANGELOG.md`。
