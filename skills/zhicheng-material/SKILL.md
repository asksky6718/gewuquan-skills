# 申报材料助手（zhicheng-material）

> 一句话：**选目标等级、申报通道与当前身份 → 得到一份逐项带出处、出具方与办理地点的材料清单 ＋ 缺件提示 ＋ 可复制的逐项生成指令。**
> 只出**准备清单与生成指令**：不给承诺话术、不代提交、不代签字、不代盖章。

## 这个技能解决什么

职业技能等级申报「要交什么、谁出、去哪办」分散在评价机构公告、属地口径与知识库条目里，逐项手工核对既慢又容易漏。本技能做三件事：

1. **按等级与通道拼清单**：公共基础材料 ＋ 目标等级对应的逐级申报材料 ＋ 所选通道的专属材料；三级／四级／五级另附可选的技能提升补贴申领材料。
2. **逐项标出处与去向**：每一项都给材料要求、出具方、办理地点，并挂知识库条目标题；知识库未单列的通用受理要件，如实标注「本条库里没有」，**不编造出处**。
3. **算缺口并给生成指令**：对照「已具备材料」勾选，算出待准备项，并给每一项生成一段可复制的草稿指令，末尾统一带上「须本人核对」与不代签字、不代盖章、不代提交的硬约束。

## 典型触发句

- 「帮我列一份职业技能等级申报材料清单。」
- 「报三级 / 高级工要交哪些材料？」
- 「走社会培训评价组织通道，我还缺什么？」
- 「逐级申报到技师，要先把下一级证书准备上吗？」
- 「技能提升补贴申领需要哪些材料？」
- 「申报表和个人承诺怎么准备？」
- 「评价机构资质怎么核验，要留什么记录？」
- 「按我的情况生成每项材料的准备说明，我自己去办。」

## 输入

| 字段 | 类型 | 必填 | 取值 | 说明 |
|---|---|---|---|---|
| `level` | select | 是 | `level5` 五级 / 初级工 · `level4` 四级 / 中级工 · `level3` 三级 / 高级工 · `level2` 二级 / 技师 · `level1` 一级 / 高级技师 | 目标等级 |
| `channel` | select | 是 | `employer` 用人单位自主评价 · `social` 社会培训评价组织 · `school` 技工院校 / 职业院校 | 申报通道 |
| `status` | select | 是 | `employed` 企业在职职工 · `student` 在校生（含应届） · `other` 灵活就业 / 其他 | 当前身份 |
| `known` | checkbox_group | 否 | `identity` · `education` · `work` · `cert` · `title` · `achievement` · `form` · `agency` · `plan` · `employer_record` · `student_status` | 已具备材料，可多选 |

示例入参：

```json
{ "level": "level3", "channel": "social", "status": "employed", "known": ["education", "work"] }
```

- 只读技能：不读取、不上传任何外部文件，不联网，不写文件。
- `known` 里可勾选的 11 项与公共清单项、通道清单项的 `key` 一一对应；等级专属项与补贴项由所填等级自动带出，不需勾选。

## 输出

- `headline`：目标等级、通道、身份以及「共 N 项材料，已具备 X 项，待准备 Y 项」的结论。
- `blocks[type=table]`（材料清单）：逐项列出材料、要求、谁出、是否已具备。
- `blocks[type=list]`（逐项生成指令）：每一项一段可复制的准备指令，末尾固定含「不要代替我签字、盖章或提交……最终由我本人核对」。
- `blocks[type=list]`（待准备项）：未勾选的材料及其「去哪办」与出处。
- `blocks[type=list]`（声明 / 说明）：4 条声明与 2 条口径说明，随每次结果返回。
- `markdown`：可带走的清单草稿，便于对照准备。
- `boundary` 与 `declarations`：随结果一并返回的边界与声明。

### 清单构成（按等级与通道自动拼装）

- **公共基础项 7 条**：身份证明、学历 / 学籍证明、工作年限证明、已有职业技能等级证书、已有职称证书（如有）、业绩 / 成果材料、申报表与个人承诺。
- **等级专属项**：二级 / 技师与一级 / 高级技师各带一条「下一级职业技能等级证书」；三级 / 高级工带一条「初级职称证明（走职称对应路径时）」。
- **通道专属项**：社会培训评价组织 2 条（评价机构资质核验记录、当期评价计划与缴费凭证）；用人单位自主评价 1 条；技工院校 / 职业院校 1 条。
- **补贴项（可选）**：目标等级为三级 / 四级 / 五级时附「技能提升补贴申领材料（可选）」。

## 人工把关点

1. **须本人核对**：所有材料的真实性、完整性，以及与当期评价计划的一致性，由本人逐项核对后再使用。
2. **不代提交**：本技能不回传任何报名系统，也不代替本人提交任何报名或申报。
3. **不代签字**：本技能不生成、不代替任何本人签名。
4. **不代盖章**：本技能不代办、不代替任何单位盖章。
5. **资格与当期口径回权威源核**：能否报、报哪一级、补贴金额与时限，以评价机构与属地人社部门当期口径为准；本技能不做资格承诺。
6. 完整清单见 `references/人工把关点.md`。

- 《人工智能训练师能报几级？各级申报条件是什么？》—— 逐级申报与等级对应的材料口径。
- 《找谁报？三类评价通道怎么选？》—— 三类评价通道的差异与专属材料。
- 《评价机构资质怎么核验？》—— 社会培训评价组织通道的资质核验与报名缴费记录。
- 《技能提升补贴能领多少？》—— 三级 / 四级 / 五级补贴申领材料口径。
- 《证书怎么查询？有哪些特性？》—— 已有证书的联网查询与核对。

- 仅引用**知识库已核验存在的条目**；未单列的通用受理要件如实标注「本条库里没有」，以评价机构当期要求为准。
- 出处与逐条对应关系见 `references/口径来源.md`。

## 边界

- **不代提交／不代签字／不代盖章**；清单末页固定标 **须本人核对**。
- 本清单只作材料准备参考，**不构成报名受理、资格认定或通过承诺**。
- 能否报、报哪一级，以及补贴金额与时限，**以评价机构与属地人社部门当期核定为准**。
- 只出材料清单与生成指令，**不给承诺话术**，不出「保过」类表述。
- 通用受理要件知识库未单列时，只标注「本条库里没有」，**不编造成出处**。
- 只读、不联网、不写文件。
