# AiToEarn 自媒体分发（aito-self-media-distribution）

> 把 **AiToEarn** 控制台的多平台分发流程（插件安装 → 账号绑定 → 发布 → 排障）整理成一套可照做的技能。

## 这个技能解决什么

AiToEarn 的分发链路有个反直觉的地方：**控制台页面本身不发发布请求**，真正干活的是**浏览器扩展**。因此踩坑高度集中在两块：

1. **插件没就绪** —— 扩展没加载好、没加域允许、没授 cookies 权限 ⇒ 后面全都发不出去；
2. **选择器用错** —— 控制台控件几乎全是 `data-testid`，用 `id` 定位会大面积失败。

本技能把这两块连同「发布四步流」「三条硬纪律」「排障清单」一并固化，并给出**只读接口核对**方法。

## 覆盖面

| 环节 | 内容 |
|---|---|
| 插件就绪 | CRX 解包 → 加载 → 域允许 → cookies 权限 → 就绪判据 |
| 账号绑定 | 控制台绑定 → 只读接口核对 `status` |
| 发布作品 | 四步流 ＋ 选择器真相 ＋ 单账号纪律 |
| 排障核对 | 现象→处置清单；只读 API 与未授权响应判据 |

已知限制（实测）：**定时发布不生效**（确认后仍按立即发布执行）；**草稿只在浏览器本地**（不落服务端）。

## 怎么装

把本目录整体放到你的技能根目录下（目录名保持 `aito-self-media-distribution`）：

- 常见技能根：`~/.workbuddy/skills/`、`~/.agents/skills/`、`~/.客户端/skills/`、`~/.trae-cn/skills/`
- 装完开新会话，问「列出你当前可用的技能」，应能看到本条。

## 怎么唤起

直接说你的事，或用触发词：

- 「插件没装 / 插件未就绪 / 发布没反应」
- 「绑定账号 / 看看账号状态」
- 「发一条 / 发布作品 / 上传图文」
- 「点了没反应 / 排期不生效 / 上传失败」

## 使用前你要准备什么

| 项 | 说明 |
|---|---|
| 实例域名 | **你自己部署**的 AiToEarn 实例地址（技能内一律占位符，由你自填） |
| 浏览器 | Chromium，以固定 profile ＋ 远程调试端口启动 |
| 驱动 | 本机已装的 Playwright Python（本技能不装包） |
| 平台登录态 | 在扩展打开的平台页内**人工扫码一次** |

## 产出样例

- **插件就绪核对表**：域名 / 扩展版本 / 域允许 / cookies / 就绪状态
- **账号状态核对表**：平台 / 账号标识 / `status` / 判定
- **发布记录**：作品 ID ＋ 分享链接 ＋ 回读到的 `publishTime`
- **排障记录**：现象—处置—实跑结果

## 边界

- **不代使用者登录其平台账号、不代填口令、不代过验证码。**
- **不代他人发布对外内容**：对外可见内容须先经负责人过目。
- 本技能**面向自部署实例**，不含、也不指向任何第三方实例与凭据。
